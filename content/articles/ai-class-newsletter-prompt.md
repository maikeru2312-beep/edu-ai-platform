金曜の放課後、来週配る学級通信がまだ白紙——多くの教室で毎週繰り返されている光景です。書きたいことはあるのです。今週の授業のこと、係活動が回り始めたこと、来週の持ち物。ただ、手元の箇条書きメモを「保護者に読んでもらえる文章」にする最後のひと押しに、毎回30分、下手をすると1時間かかってしまう。

生成AIが学級通信・学年だよりで本領を発揮するのは、まさにこの「メモから文章へ」の部分です。ゼロから名文を書かせるのではなく、**自分のメモを保護者向けの文体に整えさせる**。この使い方なら、児童生徒の個人情報を入力する必要もほとんどありません。

本記事では、安全に使えるプロンプト例とBefore/After形式の実践例を中心に、通信ならではの校内手続き（発行前の決裁・Web掲載）まで含めて紹介します。

> AIで作成した文書については、**内容の確認・修正・管理職への確認**を必ず行ってください。校内の文書作成・配布ルールに従って運用してください。

## 通信づくりのどこにAIを入れるか

学級通信は、性質の違うパーツの組み合わせでできています。AIに向く部分と教員が書くべき部分を最初に切り分けておくと、迷わず使えます。

### AIに任せやすい部分

- 季節のあいさつ文（定型性が高く、個人情報と無関係）
- 持ち物・日程などの連絡事項を整えた文章
- 家庭へのお願い文の言い回し調整
- 箇条書きメモの文章化
- 長すぎる文章の圧縮、硬い表現の言い換え
- 見出し・紙面構成の案出し

### 教員が自分で書いたほうがよい部分

- **子どもたちの様子の描写** —— 通信の価値の中心はここです。「休み時間にダンゴムシの住みかを作っていた」「音読の声が先週より大きくなった」といった観察の具体性は、教室にいない AI には出せません。AIに整えさせると文章はきれいになりますが、どのクラスにも当てはまる平板な描写になりがちです。
- 学校としての判断・方針に関わる内容
- トラブルや個別の配慮に触れる内容（そもそも通信に書くかどうか自体を管理職と相談すべき事柄です）

判断の目安はシンプルです。**「そのクラスでしか書けない部分」は教員が書き、「どのクラスでも同じでよい部分」はAIに任せる。** 保護者が読みたいのは前者です。AIで浮いた時間を前者の質に回すのが、この道具のいちばん良い使い方です。最終的な内容の責任が発行する教員・学校にあることは、言うまでもありません。

## 入力する前に：外部サービスに出してよい情報の線引き

学校の文書作成にAIを使う前に、何を入力してよいかの線引きを自分の中に持っておく必要があります。

### 入力してよい情報の例

- 一般的な行事内容・授業のテーマ（「生活科で春の植物を観察した」など）
- 全体としての児童生徒の様子（個人名なし）
- 家庭への一般的なお願い（「朝ごはんを食べて登校するよう声がけをお願いします」など）
- 架空の内容・一般的な例文
- 季節・時期に合わせたあいさつ文

### 入力してはいけない情報

- **児童生徒の氏名**
- **顔写真・個人が特定できる情報**
- **成績・評定・テストの点数**
- **障害名・診断名・要配慮情報**
- **家庭状況・保護者の個人情報**
- **生徒指導上の詳細・トラブルの経緯**
- **学校外秘の情報・未公表の方針**

注意したいのは、**氏名を消せば安全とは限らない**という点です。「車いすを使っている子が」「転入してきたばかりの子が」のように、クラスに一人しかいない状況の描写は、名前がなくても本人特定につながります。通信に書く場合も、AIに入力する場合も、「この学級の保護者が読んだら誰のことかわかるか」を基準に判断してください。迷ったら、その要素は入力せず、AIの出力を得てから手元で書き足すのが安全です。

→ 個人情報とセキュリティの詳細は[学校で生成AIを使うときの個人情報・セキュリティの注意点](/articles/school-generative-ai-privacy-security)をご参照ください。

## 箇条書きメモから配布までの5ステップ

学級通信・学年だよりをAIで作成する流れは次のとおりです。

### Step 1：書きたい内容を箇条書きにする

まず、今回の通信に入れたい内容を自分でメモします。

```
・6月の行事（プール開始、学校公開日）
・今月の授業（国語：詩の音読、理科：昆虫の体の仕組み）
・子どもたちの様子（係活動が定着してきた）
・家庭へのお願い（水着の記名、熱中症対策）
```

### Step 2：個人名や詳しすぎる情報を確認・削除する

箇条書きの中に、児童名・特定の家庭のことが含まれていないか確認します。

### Step 3：ChatGPTに依頼する

目的・読者・文体・文字数を明記して依頼します（次のセクションで詳しく説明）。

### Step 4：出力された文章を確認・修正する

AIの出力を読み、**事実と異なる点・表現が合わない点・学校の文体と違う点**を修正します。

### Step 5：校内確認ルールに沿って配布する

管理職確認が必要な場合は確認を取り、印刷・配布の手順に従います。学級通信の決裁ルールは学校ごとに違うため、次のセクションで具体的に整理します。

## 学級通信ならではの校内手続き

学級通信は、学校によって発行までの決裁の流れが大きく違う文書です。AIの利用可否だけでなく、通信そのものの取り扱いも含めて押さえておきましょう。

**まず、発行前の決裁ルールを確認する。** 学年主任や教頭の確認を経て発行する学校もあれば、担任裁量に任されている学校もあります。自校のルールが曖昧なら、最初に学年主任に聞くのが自然です。AIを使うかどうか以前の土台になります。

**次に、AI利用について情報主任・管理職に伝える。** このとき「箇条書きのメモを文章に整える用途で、児童の個人情報は入力しない」と使い方を具体的に説明すると、相手も判断しやすくなります。用途を限定して伝えるほど、話は早く進みます。

**最初の1〜2号は、AIを併用したことを添えて見てもらう。** 決裁に出すときに「下書きに生成AIを使っています」と一言伝えて文体を確認してもらえば、あとから「AIで書いていたのか」と問題になることを防げます。文体が学校のトーンと合っているかの客観的なチェックにもなります。

**Web掲載の有無を確認する。** 学校ホームページに通信を載せる学校では、通信は配布物であると同時に**誰でも読める公開文書**になります。紙で配る前提なら問題ない表現でも、Web上では学校の公式発信として読まれます。掲載対象の号は、個人が推測できる記述がないか特に念入りに見直してください。

なお、一次情報にあたるなら文部科学省「初等中等教育段階における生成AIの利活用に関するガイドライン（Ver.2.0）」です。保護者向け文書の作成は、児童生徒がAIを使う学習場面とは区別される「校務での利活用」に位置づけられ、業務改善の手段として認められている領域です。前提となるのは、個人情報を入力しない運用と、内容の最終確認を人間が行うこと。この2点は本記事の手順そのものです。原文の読み解き方は[文科省の生成AIガイドライン（Ver.2.0）の読み方](/articles/generative-ai-guideline-v2-school-reading)で解説しています。

```
以下の箇条書きをもとに、小学校の保護者向け学級通信の文章を作成してください。

個人名は使わず、学年全体の様子として書いてください。
丁寧な敬語で、400字以内にまとめてください。

【報告する行事名と日時】：
【当日の様子（箇条書き）】：
【子どもたちの感想や反応】：

```
以下の内容について、保護者向けのお願い文を作成してください。

## Before / After で見る実際の流れ

### 例①：箇条書きから学級通信の文章を作る

**【Before】教員の箇条書きメモ**

```
・生活科で学校の周りを探検した
・虫や植物をたくさん見つけた
・グループで話し合って記録カードにまとめた
・次は教室に戻って発表する
・外での活動の振り返りを家庭でもしてほしい
```

**【AIへの依頼文】**

```
以下の箇条書きをもとに、小学1年生の保護者向け学級通信の文章を作成してください。
個人名は使わず、クラス全体の様子が伝わるようにしてください。
丁寧で温かい文体で、300字程度にしてください。

・生活科で学校の周りを探検した
・虫や植物をたくさん見つけた
・グループで話し合って記録カードにまとめた
・次は教室に戻って発表する
・外での活動の振り返りを家庭でもしてほしい
```

**【After】AIが作った下書き（例）**

> 先日の生活科では、学校の周りを探検し、たくさんの発見をすることができました。草むらの中の小さな虫や、季節の植物を見つけた子どもたちは、目を輝かせながらグループで話し合い、記録カードにまとめることができました。
>
> 次回の授業では、見つけたことをクラスみんなに発表する予定です。もし機会がありましたら、「今日どんなものを見つけたの?」と、お子さんに問いかけてみてください。発見のよろこびをご家庭でも共有していただけると嬉しいです。

**【教員による修正のポイント】**

- 「目を輝かせながら」→ 実際にそういう様子だったか確認し、違う場合は削る
- 「次回の授業では」→ 正確な日程を追記する
- 「問いかけてみてください」→ 学校の文体に合わない場合は言い換える
- 全体の長さ・段落の区切り方を学校スタイルに合わせる

---

### 例②：事務的な文章を温かくする

**【Before】元の文章**

> 7月3日はプール開始日です。水着・水泳帽・タオル・ゴーグルを持参してください。健康観察カードに記入してください。

**【AIへの依頼文】**

```
以下の連絡文を、保護者に親しみやすく温かい文体に書き直してください。
内容（日時・持ち物）は変えずに、表現だけを調整してください。命令口調は避けてください。

7月3日はプール開始日です。水着・水泳帽・タオル・ゴーグルを持参してください。健康観察カードに記入してください。
```

**【After】AIが作った下書き（例）**

> いよいよ7月3日（水）からプール学習が始まります。お子さんと一緒に楽しみにしていただけると嬉しいです。
>
> 当日は水着・水泳帽・タオル・ゴーグルのご準備をお願いいたします。また、健康観察カードへのご記入もよろしくお願いいたします。安全に楽しくプールに取り組めるよう、体調を整えてご登校ください。

**【教員による修正のポイント】**

- 曜日を確認（7月3日が水曜か確認）
- 「楽しみにしていただけると嬉しいです」→ プール嫌いな子がいる場合は柔らかく
- 「ゴーグル」が必須かどうかを確認（任意の場合は表現を変える）

## AIを使っても変わらない、伝わる通信の条件

AIを使っても使わなくても、保護者向け文章で大切な4つの要素があります。

### ① 事実を書く

「何があったか」「何をしたか」を具体的に書きます。「楽しかった」だけでは伝わりません。「生活科の探検でダンゴムシを見つけ、図鑑で調べた」という事実が保護者の心に届きます。

### ② 成長を書く

「できたこと」だけでなく「どう取り組んだか」「前と何が変わったか」を伝えます。「静かに話を聞けるようになってきた」「友達の意見を聞いてから発言する場面が増えた」のように、**プロセスと変化**を伝えることが大切です。

### ③ 次の見通しを書く

「次は何をするのか」を伝えることで、保護者が家庭でも会話のきっかけを作りやすくなります。「次回は発表会です」「来週から○○の学習が始まります」という一行で、関心の継続につながります。

### ④ 家庭へのお願いは短く・明確に

「よろしくお願いします」だけでなく、「何を・いつ・どのように」を具体的に書きます。ただし、お願いが多すぎると読み飛ばされます。**1〜2点に絞って、明確に**伝えることを意識してください。

この4つに共通するのは、どれも「教員がその教室で見たこと」が出発点になっている点です。現場でよく起きるのは、AIを使い始めてから文章が整いすぎて、かえって保護者の反応が薄くなるケースです。通信で価値を持つのは文章の巧拙よりも、「うちの子のクラスのことが書いてある」と感じられる具体性のほうです。AIには整形を任せ、素材の解像度は日々の短いメモで確保する——この分担を崩さないことが、通信の質を保つ鍵になります。

## 配布前チェック：印刷ボタンを押す前に

AIの出力をそのまま使わず、次の観点で必ず確認・修正してください。

| 確認観点 | チェック内容 |
|---|---|
| **事実の正確性** | 実際にやっていない活動や、日時が違う内容が含まれていないか |
| **言い切りすぎ** | 「子どもたちは全員〜できました」など、実態と違う断定がないか |
| **個人の特定** | 「○○な子が」など、個人が推測できる表現がないか |
| **表現の温度感** | 大げさすぎ・事務的すぎ・命令的すぎていないか |
| **学校の文体** | 自校のスタイル・管理職の確認が必要な表現でないか |
| **保護者への誤解** | 意図しない受け取られ方をしないか |
| **著作権・引用** | AIが他の文章をそのまま出力していないか |

## 配ってから気づく失敗と、その防ぎ方

通信の失敗は、配布した瞬間に取り返しがつかなくなるのが特徴です。起こりやすいパターンを事前に知っておきましょう。

**失敗① 個人情報を入れてしまう**

「A君が活躍しました」など、個人名を含むメモをそのままAIに貼り付けてしまうケースです。入力前に個人名・クラス・学校名が含まれていないか確認してください。

**失敗② AIの文章をそのまま使う**

AIが「全員が意欲的に取り組みました」と書いても、実際には乗り気でない子もいます。事実と異なる記述をそのまま配布することは、保護者の信頼を損ないます。必ず内容を確認・修正してから使います。

**失敗③ やっていない活動が文章に入る**

AIは入力された情報をもとに「もっともらしい文章」を生成します。「次回はまとめる予定」と書いたつもりが「まとめました」と書かれている、というミスが起こります。動詞の時制・活動の前後関係を必ず確認してください。

**失敗④ 保護者へのお願いが強すぎる**

「必ず○○してください」「〜しないでください」など、AIが強めの命令調で生成することがあります。お願い文は「〜ようご協力をお願いいたします」程度に調整してください。

**失敗⑤ 校内ルール確認をせずに使う**

ChatGPTなどの利用について学校・教育委員会のルールがある場合、確認なしに使い始めることはリスクになります。まず管理職・ICT担当に一言確認してから活用してください。

**失敗⑥ 毎号同じ構成・同じ温度になる**

同じプロンプトを使い回していると、書き出しも結びも似た通信が続きます。保護者は毎号続けて読む読者なので、パターン化には意外と早く気づきます。文体や構成の指定をときどき変える、書き出しの一文だけは必ず自分で書く、といった崩し方を入れると単調さを防げます。

## まとめ

学年だより・学級通信へのAI活用は、**「丸投げ」ではなく「下書き・整理・言い換え」に使う**のが基本です。

**使い始めの手順：**

1. 書きたい内容を箇条書きにする
2. 個人名・詳細すぎる情報を除く
3. AIに目的・読者・文体・文字数を伝えて依頼する
4. 出力された文章を事実確認・表現修正する
5. 校内の確認ルールに沿って配布する

**守るべき3点：**

1. 児童生徒の個人情報・成績・家庭情報は入力しない
2. AIの出力はそのまま使わず、必ず確認・修正する
3. 学校・教育委員会のルールを確認してから使い始める

まずは「箇条書きのメモを保護者向けの文章に整える」使い方から試してみてください。慣れてくると、表現の引き出しが増え、通信作成にかける時間が自然と短くなっていきます。そして浮いた時間は、通信の核である「そのクラスでしか書けない一段落」に使ってください。それが、AIを使っても読まれ続ける通信と、整っているだけの通信の分かれ目です。
