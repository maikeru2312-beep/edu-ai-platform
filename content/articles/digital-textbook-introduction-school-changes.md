## 最初の単元を組む前に、順番に決める4つのこと

「来年度からこの教科はデジタル教科書を使います」と校内でアナウンスされたとき、担任が実際に決めなければならないことは、**制度の是非ではありません**。支援を必要とする児童生徒を含む学級で、ある単元から学習者用デジタル教科書を使い始めるとして、順に決まっていくのは次の4つです。

1. 導入前に、校内の誰へ何を聞いておくか
2. 初回授業の前に、デジタル教科書に固有の何を確かめるか
3. 初回授業の最中に、何を見て記録するか
4. 授業のあとで、続けるか・変えるか・この単元ではやめるかをどう決めるか

この記事は、この4段階を**1枚の記録シート**にまとめることを目的にしています。制度の全体像や端末運用そのものは扱いません。

> デジタル教科書の導入範囲・スケジュール・制度設計は段階的に進められており、変更される場合があります。最新の状況は、文部科学省および所属校・教育委員会の案内を必ずご確認ください。本記事は手順の整理です。

## 「デジタル教科書」と呼ばれるものの区別

校内の会話では次の3つが混ざりやすく、混ざったまま情報担当に相談すると話が噛み合いません。最初に区別だけしておきます。

| 種類 | 主な使い手 | 位置づけ |
|---|---|---|
| 学習者用デジタル教科書 | 児童生徒 | 紙の教科書と同じ内容を端末で読む教材 |
| 学習者用デジタル教材 | 児童生徒 | 動画・音声・ドリルなど、教科書を補う教材 |
| 指導者用デジタル教科書 | 教員 | 大型提示装置などで授業に提示するためのもの |

この記事で扱うのは、児童生徒が自分の端末で使う**学習者用デジタル教科書**です。紙の置き換えというより、音声読み上げ・拡大・書き込みなど紙にはできない操作が加わる点が、授業の組み立てに影響します。

読み上げや拡大などの機能を「その子の支援手段」として選ぶ手順（困りごとの観察から試用・見直しまで）は、[特別支援教育の支援ツールを選ぶ手順](/articles/special-needs-ict-support-tools-checklist)が扱っています。この記事では機能の分類は繰り返しません。

デジタル教科書に固有の注意として、本サイトの整理では次の2点だけを押さえておけば足ります。紙のほうがページの位置関係をつかみやすい児童生徒がいること、そして**最初の単元は使う機能を一つに絞る**こと。

## 段階1：導入前に、校内で誰に何を聞くか

デジタル教科書は、**担任一人の判断で始められるものではありません**。ライセンス・アカウント・端末設定が絡むため、単元を組む前に次の相手へ確認しておくと、初回授業の当日に止まりにくくなります。

| 確認する相手 | 確認する内容 | 返答が得られないまま始めた場合に起きること |
|---|---|---|
| 教科・学年の同僚 | どの教科・単元から使うか、紙との併用方針を学年でそろえられるか | 学級ごとに紙とデジタルの扱いが食い違い、保護者への説明も揃わない |
| 情報担当 | アカウントの配布状況、ビューアの導入状況、学級全員が同時に開けるか | 当日にログインできない児童生徒が出て、授業時間が復旧に費やされる |
| 管理職 | 保護者への説明（家庭での利用、目の健康への配慮を含む）、端末持ち帰りの方針 | 家庭学習の指示が出せず、保護者からの問い合わせが担任に集中する |
| 教育委員会（情報担当経由でよい） | ライセンスの範囲と契約形態、自治体としての導入計画 | 使える教科・期間の前提が崩れ、単元の途中で使えなくなる |

アカウントや学習ログの扱いは、**個人情報の管理の問題**でもあります。誰がどの範囲まで閲覧できるのか、卒業・転出時にデータがどうなるのかは、情報担当・管理職と共有しておきます。個人情報の共有範囲・保管・廃棄をどう決めて記録するかは、[個別の教育支援計画・個別の指導計画の書き方](/articles/individual-education-plan-writing-guide)にまとめています。

## 段階2：初回授業前に確かめる、デジタル教科書に固有の項目

端末そのものの充電・起動・ネットワーク・持ち帰りといった一般の授業前チェックとトラブル対応は、[端末を使う授業の前日準備と当日のトラブル判断：実機確認10項目と切り上げの基準](/articles/giga-device-lesson-use-guide)が扱います。ここでは、そこに含まれないデジタル教科書固有の項目だけを挙げます。

- [ ] ライセンスの範囲（対象の教科・学年・期間）を文書で確認したか
- [ ] 全員分のアカウントが発行され、児童生徒が一度はログインを試したか
- [ ] ビューアが起動し、教科書のデータが端末側に用意された状態か
- [ ] 学級全員が同時に開いても表示できるか、事前に試したか
- [ ] 最初に使う機能を一つに絞り、その操作手順だけを提示できる形にしたか
- [ ] 紙と併用してよい場面（どこは紙で読み、どこはデジタルで読むか）を決め、児童生徒に伝える言い方まで用意したか
- [ ] 開けない児童生徒が出たときの代替（紙の教科書、隣とペアで見る）を、学級全体で共有しておいたか

本サイトの整理として、最初の単元は紙と並行しながら、機能を一つだけ（たとえば読み上げだけ、あるいは拡大だけ）に絞る形をとります。初回に複数の機能を扱うと操作の説明に時間がかかりやすいためで、段階的に活用を広げる考え方は、文部科学省の学習者用デジタル教科書に関する資料でも示されています。

配慮が必要な児童生徒について、どの機能をどの場面で使うかを決めたうえで合理的配慮として記録に残す手順は、[合理的配慮の記録の書き方：避けたい書き方をよい書き方へ直す書き換え表](/articles/reasonable-accommodation-school-record)に沿ってください。この記事では記録の様式は扱いません。

## 段階3：初回授業の最中に見る項目

授業後の判定は、印象ではなく授業中に見たことを根拠にします。見る項目をあらかじめ決めておかないと、「思ったより時間がかかった」という感想しか残りません。次の6点を、授業中に記号（○＝問題なし／△＝手間取った／×＝進まなかった）で残せる形にしておきます。

| 見る場面 | 具体的に見ること | 記号の目安 |
|---|---|---|
| 開くまで | 指示から全員が教科書のページを開くまで | ○＝ほぼ全員が自力／△＝数人に個別支援／×＝学級の相当数が開けない |
| 該当ページへの到達 | 「今どこを読んでいるか」を全員が共有できているか | ○＝声かけで揃う／△＝繰り返し必要／×＝迷子が続く |
| 絞った機能の使われ方 | 決めた一つの機能が、読む・考える行為に向いているか | ○＝学習に向いた／△＝操作の練習で終わった／×＝機能で遊んだ |
| 学習内容への集中 | 教材の内容についての発言・書き込みが出ているか | ○＝出た／△＝少ない／×＝操作の話ばかり |
| 支援が必要な児童生徒 | 個別に支援した内容と、紙へ切り替えたかどうか | 事実をそのまま記入 |
| 紙との併用 | 決めた併用範囲どおりに進んだか、ずれたか | ○＝想定どおり／△＝範囲を広げた／×＝ほぼ紙になった |

最後の2行は、判定の分かれ目になりやすいところです。特定の児童生徒だけが取り残されたのか、学級全体が同じところで止まったのかで、次に打つ手が変わります。

## 段階4：授業後に「続ける・変える・やめる」を決める

観察の記号がそろったら、その場で次の単元の扱いを決めます。判定を先送りにすると、同じ組み立てのまま2回目・3回目を迎えることになります。

| 判定 | そう判断する目安 | 次にすること |
|---|---|---|
| 続ける | 開くまでと該当ページが○で、学習内容への発言・書き込みが出ている。個別支援は数人にとどまった | 同じ組み立てで次時に進み、慣れたところで機能をもう一つ足す |
| 変える（組み立てを直す） | 開くまでが△、または機能が操作の練習で終わった。学級全体が同じところで止まった | 使う機能を減らす、開く手順を板書で固定する、紙で読む範囲を広げる、教材を配布済みの状態にしてから授業に入る |
| 変える（その子に合わせる） | 学級はおおむね進んだが、特定の児童生徒だけが取り残された | その子の紙への切り替えを常時可能にし、機能の選び直しは支援ツールを選ぶ手順に沿って行う。配慮として続けるなら記録に残す |
| この単元ではやめる | 学級の相当数が×で、原因がライセンス・アカウント・同時アクセスなど担任の手の外にある | 紙に戻して単元を進め、事実（何人が開けなかったか、どの段階で止まったか）を情報担当へ返す |

判定の理由は、その日のうちに一言で残しておきます。次の担当者や次年度の自分が見るのは、判定そのものより「なぜそう決めたか」だからです。

## 記入様式：初めての単元でデジタル教科書を使う記録シート

以下は本サイト作成の参考様式です。校内の様式が別にある場合はそちらを優先してください。1つの単元につき1枚を想定し、4段階を上から順に埋めていきます。

### シートA：4段階の記録

| 段階 | 記入すること | 記入欄 |
|---|---|---|
| 単元の基本 | 教科・単元名・実施時期・学級・使う予定の機能（一つ） |  |
| 段階1（導入前） | 誰に何を聞き、いつどんな返答を得たか。未解決のまま残っている点 |  |
| 段階2（初回授業前） | 確認できた固有項目／できなかった項目。紙を併用する範囲。開けない子の代替 |  |
| 段階3（授業中） | 6つの見る場面の記号。個別に支援した児童生徒と支援した内容 |  |
| 段階4（授業後） | 続ける／変える（組み立て）／変える（その子）／この単元ではやめる のどれか |  |
| 判定の理由 | そう決めた根拠を一言で。次の単元で変える点 |  |

### シートB：この単元で紙とデジタルのどちらを選んだか

一律の正解を示す表ではありません。観点ごとに、この単元でどちらを選び、なぜそう選んだかを言語化するための欄です。同じ児童生徒でも、教科・単元・体調・利用目的によって判断は変わります。

| 観点 | 紙が向く目安 | デジタルが向く目安 | この単元の選択と理由（記入） |
|---|---|---|---|
| 学習目標 | 紙面全体を見渡して位置関係を捉えたい | 検索・拡大・音声などの機能が目標達成を支える |  |
| 読みやすさ | 書体・紙面・光の反射が本人に合っている | 拡大・配色・読み上げで困難を調整できる |  |
| 書き込み・思考整理 | 手書きで素早く全体へ書き込みたい | 修正・移動・複製が思考整理を助ける |  |
| 集中・疲労 | 画面操作や通知が負担になる | 必要な箇所だけ表示して情報量を調整できる |  |
| 授業運営 | 配布後すぐ始められる | 教員と児童生徒の環境が準備済みで、同時に開ける |  |
| 配慮が必要な子への対応 | 紙教材への変更・加工のほうが適切 | デジタルの機能が学習上の困難を低減する |  |
| 家庭学習 | 持ち帰りや通信環境に不安がある | 家庭でも同じ環境で開ける見通しがある |  |

### 記入例（完全な架空の事例）

以下は説明のための架空の記入例で、実在の学校・学級・児童生徒とは関係ありません。

- 単元の基本：小学5年・国語・説明文の単元・9月上旬・第2学級・使う機能は読み上げのみ
- 段階1：情報担当へ8月下旬に確認。アカウントは全員発行済み、同時アクセスは未検証との回答。教育委員会のライセンス範囲は国語のみで年度末までと確認。管理職へは学年通信での説明文案を提出済み
- 段階2：全員のログイン試行は済。同時アクセスは前日の朝の時間に学級全員で試し、表示を確認。紙で読むのは全文の通読、デジタルで読むのは段落ごとの読み返し、と範囲を決定。開けない場合は紙の教科書を机上に置いたまま進める
- 段階3：開くまで○、該当ページへの到達△（見出し番号での声かけを3回）、絞った機能の使われ方○、学習内容への集中○、支援した児童生徒＝読みに時間がかかる2名に読み上げの速度調整を個別に設定、紙との併用△（通読も一部デジタルになった）
- 段階4：続ける
- 判定の理由：読み返しの場面で本文についての発言が出たため。次の単元では、該当ページの共有方法を板書で固定してから始める

## 制度と最新情報をどこで確かめるか

導入の範囲やスケジュールは段階的に変わるため、まとめ記事やSNSの情報だけで判断せず、文部科学省の学習者用デジタル教科書に関するページと、効果的な活用の在り方に関するガイドラインにあたるのが確実です。読むときは、自校の対象学年・教科に関わる部分と留意事項に絞ると短時間で済みます。

そのうえで、実務上は自治体（教育委員会）からの通知が最も直接的な判断材料になります。国の資料と自治体の通知で読み取れる範囲が違うときは、自治体の通知を優先し、判断の根拠として日付とともに記録に残してください。

### この記事の適用限界

- 本記事は、公開されている資料と一般的な留意点を、担任が単元を組む順序に並べ直したものです。特定の教科書会社のビューアの操作手順、自治体ごとの契約内容、機器の設定方法は扱っていません。
- 記載の判定基準は、授業の進め方を決めるための整理であり、学習効果を測定した結果ではありません。効果の有無を示すものとして扱わないでください。
- テストや検定における配慮の扱いは実施機関ごとに異なります。個別に確認してください。
