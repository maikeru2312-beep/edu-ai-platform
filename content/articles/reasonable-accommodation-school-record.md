本人・保護者と話し合い、配慮の内容そのものは決まった。そのあと記録の欄を開いて、「書くことが苦手なので配慮する」と打ったところで手が止まる。合理的配慮でつまずきやすいのは、制度の理解よりも、決めたことを次に読む人が使える形で書き残す場面です。

この記事は、その1点だけを扱います。相談を受けてから合意に至るまでの進め方や、計画書への位置づけは別の記事へ委ね、ここでは配慮記録の文面をどう組み立てるかに絞ります。

なお合理的配慮は、障害者差別解消法にもとづき、障害のある人が他の人と平等に教育を受けられるよう、その人の必要に応じて行う変更・調整を指します。根拠は、国公立学校では障害者差別解消法第7条第2項、私立学校等の事業者では第8条第2項です（事業者の義務化は2024年4月1日施行）。考え方の枠組みは内閣府の基本方針が示し、私立学校等については文部科学省の対応指針が、国公立学校については設置者が定める対応要領が、それぞれ具体化しています。**自校にどれが当てはまるかは設置形態で変わります。**

> 合理的配慮の具体的な判断・対応は、学校・設置者・教育委員会の方針によって異なります。本記事は公的資料をもとにした一般的な整理であり、個別ケースの判断や法的な結論を示すものではありません。実際に進めるときは**所属校・特別支援コーディネーター・管理職との連携**を前提としてください。

## 「〇〇が苦手なので配慮する」では引き継げない

配慮記録でよく見かけるのは、次のような一文です。

> 書くことが苦手なので配慮する。

この一文は、書いた本人には意味が通ります。困っている場面も、実際にやっている工夫も、頭の中にあるからです。しかしこの記録を次に読むのは、その場にいなかった人です。学年が替わった担任、教科担任、進学先の担当者、そして数か月後の自分自身。読み手が知りたいのは次の4点ですが、上の一文はどれにも答えていません。

- どの場面で起きているのか（教科・時間・活動）
- 何がどう難しいのか（観察できた事実として書けるか）
- そのために学校は何をするのか（誰が、どこまで）
- いつ見直すのか（期間と、確認の方法）

裏返せば、この4点を埋めれば記録は引き継げる形になります。以下は、その埋め方を様式と文例の形にしたものです。

## 配慮記録の書き換え表（本サイト作成の参考様式）

以下は本サイトが記事用に作成した参考様式で、公的な標準様式ではありません。所属校で使用している様式がある場合はそちらを優先し、本様式は文面を組み立てるときの下書きとしてご利用ください。

### 空欄様式：配慮記録の6欄

| 欄 | 何を書くか | 記入欄 |
|---|---|---|
| 場面 | どの教科・時間・活動で生じているか | |
| 困難さ | その場面で何がどう難しいか（推測ではなく観察できた事実で） | |
| 検討した調整案 | 話し合いで出た案。採用しなかった案も残す | |
| 実施する配慮 | 誰が、何を、どこまで行うか | |
| 実施期間 | いつから、いつまで | |
| 見直し時期と方法 | いつ、何をもって確認するか | |

相談日・相談者・本人および保護者の願い・その場で答えられなかった保留事項は、この様式ではなく面談の記録側に置いたほうが、後から探しやすくなります。面談側の様式は[特別支援教育の保護者面談：準備・その場の整理・校内確認・記録の手順](/articles/special-needs-parent-collaboration)の面談・相談記録シートをご参照ください。

### 書き換え表：避けたい書き方から、よい書き方へ

配慮の内容は、記録の上では学習面・環境面・評価面のいずれかに落ちます。類型ごとに、避けたい書き方と、そこに足りない情報を並べます。

| 類型 | 避けたい書き方 | 足りない情報 | 書き換えの方向 |
|---|---|---|---|
| 学習面 | 書くことが苦手なので配慮する | 場面／困難さの中身／学校が行うこと | どの授業のどの作業で時間が足りなくなるのかを書き、その作業を代える手立てを書く |
| 環境面 | 落ち着かないので配慮する | 何に反応しているか／いつ使う手立てか | 取り組みが中断する引き金と、それを避ける場所・道具・タイミングを書く |
| 評価面 | テストが苦手なので配慮する | 学習目標を変えるのか、答え方を変えるのか | 学習目標は変えないと明記し、解答方法・時間・場所のどれを調整するかを書く |

避けたい書き方に共通するのは、原因が本人の性質として書かれていて、学校が何をするのかが書かれていない点です。主語を本人から、場面と学校の行為へ移すと、そのまま引き継げる文になります。

### 困難さの欄は、推測ではなく観察できた事実で書く

6欄のうち最も書きにくいのが困難さの欄です。ここに本人の内面の推測を書いてしまうと、次の担当者はその推測ごと引き継ぐことになり、あとから事実に戻せなくなります。解釈と事実を分けて書く方法そのものは[特別支援教育における行動記録の取り方](/articles/special-needs-behavior-record-guide)の「記録様式に最低限入れる項目」（事実の欄と「気づき・仮説」の欄を分ける）にまとめています。ここでは、配慮記録の困難さの欄で起きやすい置き換えだけを挙げます。

| 推測が混じった書き方 | 観察できた事実に置き換えた書き方 |
|---|---|
| やる気が続かない | 15分ほどで手が止まり、そこから再開までに時間がかかる |
| 音に敏感である | 廊下側の席で課題に取り組んだ時間帯に、中断する回数が多かった |
| 読むことが嫌い | 教科書の本文を読む場面で、行を飛ばして読み直すことが続いた |
| 自信がない | 学級全体の場で発表を求められた場面で、応答がなかった |

いずれも、本人の内面や特性への帰属（やる気・敏感・嫌い・自信）を、場面と観察結果へ戻したものです。**困難さの欄は診断名や特性の名前を書く欄ではない**と考えると、迷いが減ります。

原因の解釈を書き添える必要がある場面もあります。その場合は「〜と考えられる」と推測であることを明示して、事実の記述と混ぜないようにします。

### 完全な架空の記入例

以下はすべて完全な架空の事例です。実在の児童生徒・学校とは関係ありません。

| 欄 | 学習面の例 | 環境面の例 | 評価面の例 |
|---|---|---|---|
| 場面 | 国語・理科で板書を書き写す場面 | 教室での個別課題の時間 | 学期末のまとめテスト |
| 困難さ | 書き写しに時間がかかり、説明を聞く時間が確保できていない | 周囲の音や動きで手が止まり、再開までに時間がかかる | 手書きでの記述に時間がかかり、解答欄が埋まらない |
| 検討した調整案 | A案：板書写真の確認／B案：要点プリントの配布／C案：タブレットへの入力 | A案：課題時間だけ席を替える／B案：別室での実施／C案：イヤーマフの使用 | A案：時間の延長／B案：解答をタイピングに変更／C案：口頭での説明に代える |
| 実施する配慮 | 授業後に板書写真を確認できるようにする（A案） | 個別課題の時間に限り、教室後方の刺激の少ない席を使う（A案） | 学習目標は変えず、記述式の解答をタイピングで行う（B案） |
| 実施期間 | 2026年9月から12月まで | 2026年9月から12月まで | 2026年12月の学期末テスト |
| 見直し時期と方法 | 12月の個別面談で、本人の負担感と提出物の状況を確認 | 12月の個別面談で、課題に取り組めた時間の記録を確認 | 12月の個別面談で、解答量と本人の感想を確認 |

6欄をつないで文章にすると、学習面の例は次のようになります。

> 国語・理科で板書を書き写す場面で、書き写しに時間がかかり、説明を聞く時間が確保できていない。そのため、授業後に板書写真を確認できるようにする。実施期間は2026年9月から12月までとし、12月の個別面談で本人の負担感と提出物の状況を確認して見直す。

環境面・評価面も同じ順につなげます。文体をそろえることより、6欄が全部埋まっていることのほうが、引き継ぎでは効きます。

### 見直し時期の欄は、日付だけでは足りない

「12月に見直す」とだけ書かれた記録は、その日が来ても、何を見て判断すればよいかが決まっていません。日付と一緒に、何を材料に確かめるかまで書いておきます。

- 本人に聞くこと（負担は減ったか、この方法を続けたいか）
- 記録から見ること（提出物、取り組めた時間、活動への参加の状況など）
- 校内で確かめること（他の教科や場面でも同じ手立てが使えているか）

そのうえで、続ける・内容を変える・終了するのいずれかを書きます。「継続」の二文字だけが並ぶ記録は、見直した事実そのものが残らず、次の担当者には何年前からそのままなのかも分かりません。

→ 配慮に使う支援ツールの分類と選び方は[特別支援教育の支援ツールを選ぶ手順：困りごとの観察から試用・見直しまで](/articles/special-needs-ict-support-tools-checklist)にまとめています。この記事では、選んだ手立てを記録の文にする部分だけを扱います。

## 全員向けの整備は、配慮の記録に書かない

記録が混み合う原因のひとつは、学校全体で整えている条件まで個別の配慮欄に書いてしまうことです。両者は、記録上の置き場所が違います。

| 観点 | 基礎的環境整備 | 合理的配慮 |
|---|---|---|
| 対象 | 全員・学校全体 | 特定の児童生徒 |
| 決める主体 | 学校・設置者 | 学校と本人・保護者の合意 |
| 記録の置き場所 | 学校の教育計画・整備計画 | 個別の記録・計画 |
| 例 | 1人1台端末の整備、大型提示装置の設置 | 特定の児童生徒に音声入力や拡大表示を認める |

「全員がタブレットで板書を撮影してよい」という学級のルールは、整備の側です。そのルールがない中で特定の児童生徒にだけ撮影を認めるなら、配慮の側になります。同じ行為でも、全員に開かれているかどうかで書く場所が変わると考えると、迷いにくくなります。

配慮の側に書くときは、目標や評価の基準を変えるのではなく、その子どもが目標に向かうための手段を調整した、と読める書き方にします。評価面の記入例で「学習目標は変えず」を先に書いているのは、この読まれ方をあらかじめ確定させるためです。

→ 記録した配慮を個別の教育支援計画・個別の指導計画のどちらに、どの粒度で載せるかは[個別の教育支援計画・個別の指導計画の書き方：学校現場で使える基本ガイド](/articles/individual-education-plan-writing-guide)をご参照ください。

## 要望どおりに実施できないときに、何を書き残すか

検討の結果、相談された内容をそのままの形では実施できない、という結論になることがあります。このとき記録に残すべきなのは「できない」の一語ではなく、どこまでなら実施できるかの線と、その線を引いた材料です。

過重な負担かどうかは、事務・事業への影響の程度、実現可能性の程度、費用・負担の程度などを考慮して、個別の事案ごとに具体的に判断するものとされています（内閣府の基本方針。私立学校等では文部科学省の対応指針、国公立学校では設置者の対応要領が同じ考え方を具体化しています）。これは担任が一人で結論を出す種類の判断ではありません。担任の役割は、判断の材料を記録の形にして校内へ渡すところまでで、判断の主体や手順は所属校・設置者のルールで確認してください。

記録に残しておく材料は、次の4つです。

- 相談された内容と、その目的（何ができるようになることを求めているか）
- 実施できる範囲と、できない範囲の境目
- 検討した代替案と、その根拠になった事実
- 誰に相談し、どこで判断されたか

「できない」だけで終わった記録は、次年度に同じ相談を最初からやり直させます。代替案まで書いてあれば、その案が合わなかったという事実そのものが、次の検討の出発点になります。

→ その場で即答できない要望を校内確認へつなぐ手順と言い方の例は[特別支援教育の保護者面談：準備・その場の整理・校内確認・記録の手順](/articles/special-needs-parent-collaboration)に、校内で誰にどの順で相談するかは[特別支援教育における行動記録の取り方：支援に生かす観察と記録の基本](/articles/special-needs-behavior-record-guide)の校内共有の項にまとめています。

## 記録を書くときに迷いやすい点

**口頭の相談だけで進めてよいか**

進めること自体は可能ですが、記録は残す前提で考えたほうが後で困りません。口頭のやり取りだけで続けた配慮は、担任が替わった時点で根拠が消えます。相談を受けた日付・場面・依頼の中身を短く書いておくだけでも、次の検討の出発点になります。

**診断書がないときの書き方**

配慮は本人の困難さの実態にもとづいて検討するものとされています（内閣府の基本方針および、自校に適用される対応指針または対応要領）。診断や専門機関の情報がある場合は検討の参考になりますが、記録に書くときは診断名そのものより、授業のどの場面で何が起きているかを書くほうが引き継ぎに使えます。必要書類の要否は、所属校・設置者に確認してください。

**通常学級に在籍する児童生徒の場合**

特別支援学級・特別支援学校に限った話ではなく、通常学級に在籍する児童生徒についても記録は同じ形で残ります。学級のルールとして全員に開いた工夫は整備の側、個別に合意した調整は配慮の側という書き分けも、そのまま当てはまります。個別の記録をどの書類に載せるかは、所属校の運用で確認してください。

**一度書いた配慮を終了するとき**

見直し時期の欄があるのは、終わりを書けるようにするためです。不要になった、あるいは合わなかったという結論も、本人・保護者と確認したうえで記録に残します。終了の記録がないと、次の担当者は続けるべきかどうかを判断できません。

**評価や試験の場面で追加して確認すること**

評価場面に固有の確認事項は[そのICT利用は合理的配慮か、教育課程上の指導か：仕分けから計画・評価場面までの筋道](/articles/special-needs-ict-reasonable-accommodation)にまとめています。高校入試や資格検定の配慮申請は、各実施機関が独自の手続を定めているため、所属校を通じて早めに確認してください。

**記録に含まれる個人情報の扱い**

共有範囲・保管・廃棄の考え方は[個別の教育支援計画・個別の指導計画の書き方：学校現場で使える基本ガイド](/articles/individual-education-plan-writing-guide)の個人情報と共有範囲の項に、生成AIや外部サービスへ入力してよい情報の線引きは[学校の校務で生成AIを使う前の判断ガイド：5業務の使い分けと確認手順](/articles/ai-koomu-kaizen-nyumon)の校務ゲート2にまとめています。誰がどの配慮を受けているかという個別の情報は、共有範囲の外へは出さないことが前提になります。
