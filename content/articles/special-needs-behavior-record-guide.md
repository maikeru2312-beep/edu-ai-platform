「行動の記録を取っておいて」と言われても、何を・どこまで・どの様式で書けばよいのか分かりにくいことがあります。気になる場面が一日に何度もあっても、時間が経つと細部は思い出しにくくなります。記録が断片的だと、ケース会議や支援の検討に必要な情報が不足することがあります。加えて、困難な場面ばかりを書きためると「この子の悪い記録を集めているようで気が引ける」と感じ、ペンが重くなることもあります。特別支援教育において、行動記録はこうした点でつまずきやすい仕事です。

その後ろめたさは、記録の目的がはっきりしていないときに生まれます。行動記録は子どもを評価・批判するためのものではなく、環境や状況を整理し、本人が過ごしやすくなる手がかりを見つけるためのツールです。つまずきの多くも、書く技術ではなく「何のために・どの粒度で書くか」を先に決めていないことから来ます。この記事は、様式より先に決める「記録の粒度」から始めて、ABC記録の書き方、そのまま使える空欄様式と架空の記入例、校内で共有・相談するときの順番までを一続きで示します。文中の記録例・児童名はすべて架空のものです。

なお、この記事は支援の参考情報を提供することを目的としており、個別の医療的・法的・行政的判断を代行するものではありません。実際の支援計画の策定にあたっては、専門機関や管理職、特別支援教育コーディネーターと連携して進めてください。

## 行動記録は、子どもを責めるための記録ではない

行動記録と聞くと、「問題を記録して後で叱責の根拠にする」というイメージを持たれることがあります。しかし特別支援教育における行動記録の目的は、まったく異なります。記録の目的は、**本人がなぜその行動をとるのかを理解し、環境・指導・支援を改善するためのデータを集めること**です。

子どもの行動には、必ず背景があります。感覚の過敏さ、見通しのなさ、言語的なコミュニケーションの難しさ、体調、周囲の環境など、さまざまな要因が重なって行動として現れます。「また同じことをした」という視点ではなく、「今日はどういう状況でその行動が起きたか」という視点で記録します。言葉づかいが批判的・評価的にならないよう、「暴れた」ではなく「机を叩いた」「その場から離れた」というように、観察できる事実を書くのが基本です。障害名や診断名だけで支援方法を決めつけることも避けてください。同じ診断名でも困難の現れ方は一人ひとり異なります。記録はあくまで「この子の、この状況での行動」を積み重ねるものです。

本サイトでは、行動記録を「子ども理解の技術」であると同時に、教員自身の判断を支える文書でもあると考えています。支援の根拠を問われたとき、印象や記憶ではなく記録で説明できることは、子どもを守ると同時に教員を守ります。

## 何を記録するか

行動記録に入れる情報は、次の5つに整理できます。

- **基本情報**：日時（年月日・曜日・時刻）、場面（授業中・休憩時間・給食・移動中など）、記録者、対象の児童生徒（実名ではなく記録上の識別子を用いることを推奨します）
- **行動の内容**：観察できる事実として書きます。「落ち着きがなかった」は解釈が入っており、後で読んだ別の教員が場面を再現できません。「席から3回立ち上がった」「隣の児童に声をかけ続けた」「手でノートを覆って書こうとしなかった」のように書きます
- **強度・頻度**：どのくらい激しかったか、何回起きたか
- **前後の状況**：行動の前にあったこと（先行事象）と、行動の後に起きたこと（結果事象）。ABC記録の核心にあたる部分です
- **回復の様子**：落ち着くまでにどれくらいかかったか、何がきっかけで落ち着いたか

## 記録の粒度をどう決めるか

上の5つをすべて毎回書こうとすると、ほぼ確実に続きません。行動記録で最初に決めるべきなのは様式のデザインではなく粒度、つまり「どこまで細かく書くか」です。粒度は次の3つの基準で決まります。

### 基準1：その記録を最終的に誰が読むか

- 自分の日々の支援の手がかりにしたい → 1日1〜3行のメモで足ります。
- ケース会議や外部機関との連携に使いたい → ABC記録のような構造化された記録を、対象場面を絞って（気になる場面だけ）つけます。
- 支援を変えた効果を確かめたい → 頻度や時間帯のカウント記録が中心で、文章はほとんど要りません。

目的が決まっていない記録は、詳しすぎるか粗すぎるかのどちらかに転びます。「この記録を最終的に誰が読むか」から逆算するのが早道です。

### 基準2：明日も続けられる量か

初日に気合いを入れてA4半ページ書いた記録は、多くの場合1〜2週間で止まります。本サイトが運用の目安としているのは、「授業の合間や放課後の5分以内に書き終わる量」を上限にすることです。詳しい記録が必要な日だけ厚く書き、通常の日は1行で済む——そういう二段構えの様式にしておくと現実的です。

### 基準3：自分以外が読んで場面が浮かぶか

粒度をどれだけ落としても、削ってはいけないのは「場面（いつ・どこで・何の活動中か）」です。「離席3回」だけの記録は後から読み返しても使えませんが、「国語・書字課題・離席3回」まで書いてあれば、1行でもパターン分析の材料になります。

### 記録様式に最低限入れる項目

自作の記録用紙やスプレッドシートを作るときは、次の項目が揃っているかを確認してください。

- 日付・曜日・時刻（または時間帯）
- 場面（教科・活動）
- 行動の事実（解釈と分けて書く欄にする）
- 直前の状況（A）・直後の対応と本人の変化（C）
- 落ち着くまでの時間と、落ち着いたきっかけ——次に同じ場面が起きたときの対応の根拠になります
- 記録者——複数人で記録する場合、誰の視点かという情報自体が分析の材料になります
- うまくいった場面・落ち着いていた場面を書く欄

最後の欄は空欄の日があっても構いません。「書く欄がある」こと自体が、困難な場面だけを追いかける記録になるのを防ぎます。また「解釈と分けて書く」については、解釈を書くこと自体は悪くありません。事実の欄に混ざることが問題なので、最初から「気づき・仮説」の欄を別に設けておくと、自然に書き分けられます。

この記事の後半に、気になった1件を丁寧に書く粒度に対応した空欄様式と、その架空の記入例を置いています。粒度が決まったら、そこから欄を減らして自分の学級用に調整してください。

## 気になった1件をA・B・Cの3欄に分ける

ABC記録は、行動を「A（Antecedent：先行事象）」「B（Behavior：行動）」「C（Consequence：結果事象）」の3つに分けて整理する方法です。基準2を満たしやすいのは、たくさん書くことではなく、その日最も気になった1件だけを3欄に分けて書くやり方です。

- **A：直前に何があったか**——活動の種類や内容（書く課題・グループ活動・体育など）、指示や声かけの内容と方法、騒音・光・においなどの感覚的な刺激、その日の体調や睡眠（把握できる範囲で）、前の活動から切り替えが必要だったか、他の児童生徒との直前のやりとり
- **B：何が起きたか**——「問題行動があった」という総括ではなく、観察できる事実を書きます。架空の例：「Aさんは、漢字練習のプリントを配られた直後に、プリントを折り曲げて机の中に入れ、窓の外を見続けた。声をかけても返事をしなかった」
- **C：直後に何が起きたか**——教員や周囲の反応、本人の様子の変化、活動がどうなったか。架空の例：「担任が近づき、小声で『難しいね』と声をかけた。Aさんはしばらくして顔を上げ、5分後に書き始めた」

複数の出来事が重なる時間帯には、ABC記録は追いつきません。無理にすべてを詳細に書こうとせず、「最も気になった出来事」を1件丁寧に書くことを繰り返すほうが続きます。記録用紙や記録ファイルには個人情報が含まれるため、机上への放置や持ち帰り時の紛失がないよう、学校のルールに従った保管方法を確認してください。

## 「何回・いつ・どの場面で」を数える記録

ABC記録が1件を深く書く方法だとすれば、頻度・時間帯・場面の記録は「どのくらいの割合で起きているか」を把握する方法です。文章はほとんど要らないので、基準2とは相性のよい記録です。

- **頻度**：一定期間に何回起きたかを数えます。「1時間の授業の中で席を立つ回数」のように決めておくと、週をまたいで増減の傾向が見えます。タリーシート（正の字でカウントする用紙）にすると負担が減ります
- **時間帯**：1日を時間帯に区切って数えます。「午前の1・2時間目に多い」「給食後に多い」といったパターンが見えると、その時間帯の環境要因や疲労との関連を検討できます
- **場面**：「国語の書く課題で多い」「体育のチーム活動で多い」が分かると、課題の難易度・感覚的な刺激・グループの人間関係といった場面固有の要因を掘り下げられます

数えるときに落ちやすいのが、**行動が起きなかった時間帯・場面**です。特別支援教育では、困難の記録に比べて「落ち着いていられた条件」の記録が慢性的に不足します。本サイトの様式に「うまくいった場面の欄」を置いているのは、この不足を見落とさないためです。

## 直前・直後より少し広く状況を見る

行動を理解するときは、直前・直後の出来事だけでなく、その日の状況も合わせて見ます。毎回書く必要はなく、「その日特に気になった変化」として一言メモしておく程度で、後の振り返りに効きます。

- **環境**：騒音（隣のクラスの声・廊下の音・工事音）、視覚的な刺激（掲示物の多さ・光のちらつき）、温度・湿度・におい、座席の位置
- **活動の特性**：課題の種類・難易度・長さ・切り替えの多さ。「長い書字課題の後半に起きやすい」が分かれば、課題量の調整や途中休憩の挿入を検討できます
- **人的環境**：周囲の児童生徒との関係、教員・支援員の言葉かけの方法、担任の不在や支援員が別の子の対応中といったその日の変化
- **本人の状態**：体調・睡眠・食事など、把握できる範囲で

本人の状態については、「これは○○が原因」といった診断的な解釈は教員の役割ではありません。状態の変化を事実として記録するにとどめ、医療的な判断が必要な場合は専門機関への相談を検討してください。

## 落ち着くまでの時間と、落ち着いたきっかけ

困難が起きた後、本人が落ち着くまでにかかった時間を書いておくと、支援の介入後に回復が早まっているか、週末が近いほど時間がかかるといった疲労との関連、どの声かけが有効かを、後から検討できます。

そのためには「何をもって落ち着いたとするか」を先に決めておく必要があります。「席に戻って課題に取り組み始めた」「声かけに応答するようになった」「自分から次の活動の準備を始めた」のように観察できる行動で定義し、担任と支援員の間で目安をそろえておくと、記録者が変わっても判断がぶれません。

時間と同じくらい大事なのが、落ち着いたきっかけです。「クールダウンスペースに移動した後、10分で落ち着いた」「支援員がそばに静かにいることで5分後に落ち着いた」「特に介入せず見守った結果、自分でリセットできた」——ここが、次に同じ場面が来たときの対応の根拠になります。

## 支援の見直しは「よくなった気がする」で行わない

記録をつける目的の一つは、支援が効いているかを印象ではなく記録で確かめることです。次の3つを決めておくと、見直しが「気がする」で終わりません。

**定期的に読み返す時間を決める**——週1回・月1回など、記録をまとめて読み返す時間を先に確保します。見るのは、頻度が増えているか減っているか、起きる場面が変わっているかです。

**支援を変えたら、変更の前後を比べる**——座席変更・スケジュールの視覚化・クールダウンスペースの設置などを導入したら、導入前後の記録を並べて比較します。ただし行動の変化は、季節・学年の進行・家庭環境の変化など支援以外の要因によっても生じます。一つの要因だけで効果を断定することは慎重に行ってください。

**うまくいっている支援も残す**——見直しでは課題のある部分に目が向きますが、「この支援は有効だった」という記録は、引き継ぎや来年度への申し送りでそのまま使えます。「何がこの子に合っていたか」を具体的に伝えられる材料になります。

粒度を決めて続けた記録は、[個別の教育支援計画・個別の指導計画の書き方](/articles/individual-education-plan-writing-guide)の評価欄や、[合理的配慮の記録の書き方](/articles/reasonable-accommodation-school-record)の根拠資料にそのまま使えます。

## 記録を外に出す前に、誰の了解が要るか

行動記録は担任一人で抱え込まないほうが支援の質は上がります。ただし記録は個人情報を含む学校の文書なので、「誰に見せるか」によって先に確認しておく相手が変わります。

### 共有・相談の順番

記録は「つけ始めるとき」と「外に出すとき」で、確認する相手が変わります。本サイトで整理している順番は次のとおりです。

1. **記録を始める段階**：学年の同僚と特別支援教育コーディネーターに一言伝えます。校内に既存の記録様式や運用ルールがあることは多く、独自様式で始めてから作り直すのは二度手間です。
2. **記録がたまってきた段階**：コーディネーターと内容を共有し、ケース会議にかけるかどうかを相談します。1人の記録では見えない場面（専科の授業・休み時間など）を誰が補うかも、ここで決められます。会議資料に載せる情報は必要最小限にとどめ、会議後の資料の扱いも同時に決めておきます。
3. **保護者に見せる・外部機関に渡す段階**：事前に管理職に諮ります。記録は学校の文書であり、外に出す判断は担任個人ではなく学校として行うものです。
4. **外部機関との共有**：保護者の了解を得てから行います。

3と4が抜けたまま善意で情報提供をして、「勝手に共有された」という保護者との行き違いになることがあります。記録が支援に役立つものであるほど外に出したくなりますが、出す前にワンクッション、を習慣にしてください。

引き継ぎ（学年が上がるとき・担任交代・進学や転学）も「外に出す」場面の一つです。引き継ぎ先の教員や機関との共有範囲について保護者の了解が要るかどうかは、3と同じ手順で確認します。

### 保管・共有範囲・廃棄は計画の文書と同じルールで

記録を見せる相手の限定、保管場所とアクセスの管理、校外への持ち出し、保存年限と廃棄の方法は、行動記録だけの別ルールにせず、個別の指導計画と同じ扱いで運用します。判断の基準は[個別の教育支援計画・個別の指導計画の書き方](/articles/individual-education-plan-writing-guide)の個人情報の項にまとめてあります。

行動記録に固有の注意が一つあります。行動記録は、保護者から開示を求められる可能性のある文書です。「本人や保護者が読んでも、支援のための記録だと伝わる書き方になっているか」を、つけ始めの段階から意識しておくと、共有や開示の場面で慌てずに済みます。

### 記録の本文は、外部サービスに入力しない

デジタルで記録する場合は、学校が認めているシステム・ツールの範囲内で使うことが前提です。そのうえで、生成AIを含む外部サービスには行動記録の本文そのものを入力しない、を原則にしてください。入力してよい情報の線引きと、氏名を伏せても特定されうる理由は、[学校の校務で生成AIを使う前の判断ガイド](/articles/ai-koomu-kaizen-nyumon)の入力情報のゲートで整理しています。

### 保護者に持ち出すのはどの部分か

保護者に伝えるのは記録のすべてではなく、面談で扱うと決めた場面の事実と、うまくいっている場面の記録です。何をどう選び、どう伝え、診断的な表現をどう避けるかは、[特別支援教育の保護者面談：準備・その場の整理・校内確認・記録の手順](/articles/special-needs-parent-collaboration)に手順としてまとめてあります。

## 手法に迷ったら公的資料に立ち返る

行動観察や記録の手法は、書籍や研修によって用語や細部が微妙に異なります。校内で「どの流儀でやるか」がぶれてきたと感じたら、次のような公的資料に立ち返ると整理しやすくなります。

- 文部科学省「生徒指導提要」令和4年改訂版——チームでの支援やアセスメントの考え方が整理されています。行動記録そのものの様式集ではありませんが、「記録を誰と、何のために共有するか」を考える土台になります
- 国立特別支援教育総合研究所（NISE）の研究成果・実践資料——特別支援教育に特化した資料が公開されており、行動面の支援や実態把握について具体的な知見が得られます
- 所属自治体・教育委員会の手引——記録の保存年限や共有ルールなど、最終的に従うべき運用はここに書かれています

こうした資料の使いどころは、手法の正しさを一人で確かめることではなく、校内で説明するときの共通の拠り所にすることです。「私のやり方です」ではなく「この資料のこの考え方に沿っています」と言えると、同僚や管理職との合意形成がずっと楽になります。

## 記録が止まるときの原因は、たいてい二つ

記録が続かない原因は、意志の弱さでも様式の出来でもありません。本サイトの整理では、次の二つに集約されます。

### 書く時間が1日の流れに固定されていない

一番の原因は、書く時間がどこにも確保されていないことです。「子どもの下校後、最初の5分で書く」「帰りの会の直後に書く」のように、書くタイミングを1日の流れの中に固定してしまうのが結局いちばん確実です。詳細なABC記録を毎回つけようとして負担が大きくなった場合も、様式を作り直すより先に、粒度の3基準に立ち返るほうが早く戻せます。

### 記録が担任一人に集中している

担任一人が記録を担当すると、担任が見ていない場面の情報が抜け落ちます。支援員・専科・他の教科担任など複数の目で記録すると、場面による違いが見えます。誰がどの場面を補うかは、前述の共有・相談の順番の2の段階で決めておきます。

## そのまま使えるABC行動記録シート（本サイト作成の参考様式）

次の表は、行動の良し悪しを評価するのではなく、観察できた事実を短く分けて記録するための参考様式です。診断名や推測ではなく、第三者が見ても同じ場面を想像できる表現を使います。

| 日時・場面 | A：直前の状況 | B：観察した行動 | C：直後の状況 | 継続時間・回数 | 次回試す環境調整 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

### 完全な架空記入例

> **架空例です。実在する児童生徒・学校・出来事とは関係ありません**。この例だけで行動の理由を決めつけず、複数回の記録と本人・保護者・校内関係者から得た情報を合わせて検討します。

| 日時・場面 | A：直前の状況 | B：観察した行動 | C：直後の状況 | 継続時間・回数 | 次回試す環境調整 |
|---|---|---|---|---|---|
| 10月8日 2時間目、個別課題から片付けへの切替 | 教員が口頭で「終わり、片付けます」と伝え、机上の教材に手を伸ばした | 教材を両手で押さえ、「まだ」と2回言った | 教員が次の活動を絵で示し、残り1問を終えてから片付けた | 約2分 | 終了3分前に予告し、「残り1問→片付け」のカードを示す |

この記録から言えるのは「切替時に上記の行動が観察された」ことまでです。「予定変更が苦手だから」などの理由は、追加の記録なしに断定しません。

## 明日、1枚目を書き始めるまで

順番はいつも同じです。まず粒度を決めます——この記録を最終的に誰が読むか、放課後の5分以内に書き終わるか、自分以外が読んで場面が浮かぶか。次に、その粒度に合う欄だけを残した様式を用意します。上のシートは、気になった1件を丁寧に書く粒度に対応したものです。最後に、書く時間を1日の流れの中に固定します。ここまで決まっていれば、様式が手書きでもスプレッドシートでも記録は残ります。

書けた記録から言えるのは、そこに書いた場面で観察された事実までです。「予定変更が苦手だから」のような理由づけは、複数回の記録と、本人・保護者・校内関係者から得た情報を合わせて初めて検討できます。この打ち切り線を守ることが、記録を子どもへの評価ではなく支援の材料にとどめる方法です。

行動記録の価値は1枚では現れず、2週間、1か月と積み重なって初めてパターンとして見えてきます。1日1行でも続いた記録は、気合いを入れて3日で止まった詳細な記録より、ずっと多くのことを教えてくれます。

なお、行動記録の活用方法や個別の支援計画の策定については、特別支援教育コーディネーター・管理職・専門機関と連携しながら進めることをお勧めします。所属校・自治体・設置者によって運用上のルールが異なる場合があります。
