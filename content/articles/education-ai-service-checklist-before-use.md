## 候補に載せるかどうかだけを、その場で決める

新しいAIサービスの情報は、判断の準備が整う前に届きます。展示会で見たデモ、職員室に置かれたパンフレット、同僚の「無料で使い始めた」という一言。指が登録ボタンの上で止まるのは慎重すぎるからではなく、まだ何も確かめていないと気づいているからです。

ただし、その場で決められるのは導入の可否ではありません。決められるのは一歩手前の一次判定、つまり**このサービスを学校として導入候補に載せてよいか**という一点です。答えは3つしかありません。

- 候補にする——正式な確認経路（情報担当・管理職・設置者）へ持ち込む
- 保留——何が分かれば判断できるかを書き残し、再検討日を決める
- 候補にしない——ここで止める。理由を1行だけ残しておく

導入するかどうかは、最終的に学校・設置者が組織として決めます。この記事が扱うのは、その組織的な判断に持ち込む価値があるかどうかを、言い出した本人が1枚の様式で見分ける段階だけです。

> 本記事は一般的な確認観点の整理です。実際の導入可否は、サービスの最新の利用規約・プライバシーポリシーと、所属校・教育委員会の方針を必ず確認のうえ、組織として判断してください。「無料だから安全」「有名だから大丈夫」とは限りません。

## 一次判定で見るAI固有の3点

一般的なICTサービスとの違いは、入力した内容がその場の処理で終わらず、保存され、ときにサービスの改善に使われ、新しい出力を生むことです。ここから、他の外部サービスの確認では出てこない論点が3つ生まれます。

### 入力の二次利用と、その既定値

| 確認項目 | 見るポイント |
|---|---|
| 学習への利用 | 入力内容がモデルの学習・サービス改善に使われるか |
| オプトアウト | 止められるか。設定はどこにあり、既定値はどちらか |
| 適用範囲 | 設定は個人単位か、管理者が組織全体へ一括で適用できるか |
| 保存 | 入力・出力・利用ログが、どこの国・法域に、どのくらい残るか |
| 第三者提供 | 入力データが外部に提供・共有されることがあるか |
| 削除 | 個別のデータを削除できるか。手順が公開されているか |

判定を分けるのは、二次利用の有無そのものよりも既定値です。オプトアウトできる設計でも、既定でオンなら、使い始めた一人ひとりが設定に気づくまでの間は二次利用されます。学校として候補に載せるなら、管理者側でまとめて既定を変えられるかまで確かめます。プランや管理者設定によって扱いが変わることもあるため、確認は実際に使うプランで行います。

### 生成物の権利と、責任の所在

- 生成物を授業で配布・掲示・公開してよいかは、規約の側で条件が付くことがある
- 生成物が既存の著作物に似てしまう可能性はゼロではないため、確認せずに配布・公開しない
- 出力の誤りについての責任は、使った教員・学校が負う

「AIが作ったから自由に使える」とは言えず、「AIがそう言ったから」も説明にはなりません。一次判定の段階で確かめるのは、生成物の利用条件が規約に書かれているかどうかまでです。出力を誰がどう確認する運用にするかは、[学校の校務で生成AIを使う前の判断ガイド](/articles/ai-koomu-kaizen-nyumon)の校務ゲート4で決めます。

### 管理者設定とログイン方式

- 管理者（学校・設置者）が、使える機能や利用範囲を設定・制限できるか
- ログインの方式——既存の学校アカウントと連携できるか、個人アカウントの登録が必要か
- 契約の主体が誰になるか（個人・学校・設置者）

この3点が一次判定で効くのは、個人アカウントに校務の下書きを入れる形しか取れないサービスだと、情報管理のルールに触れる場合があるためです。管理者機能が有料プランでのみ提供されることもあります。「とりあえず無料登録」で先にアカウントを作ってしまうと、この確認が後回しになります。

## 利用規約のどこを見るか

規約とプライバシーポリシーを頭から通読する必要はありません。一方で、決まったキーワードを検索すれば済むわけでもありません。文書の構成も用語も、サービスごとに違うからです。

探す領域を先に持っておき、そのサービスの文書構造に当てはめて探します。

| 探す領域 | AIサービスで確かめること |
|---|---|
| 取得する情報 | 入力欄に打ち込んだ内容そのものが、取得対象に含まれるか |
| 利用目的 | 「サービスの改善」「モデルの学習」に使うと書かれているか |
| 設定・オプトアウトの説明 | 学習利用を止める設定の場所と、既定値 |
| 保存・保管 | 入力と出力が、どこに、いつまで残るか |
| 第三者提供・委託 | 外部の事業者に渡るか。渡る場合は誰にか |
| コンテンツ・生成物の権利 | 入力した文章と、生成された文章・画像の権利がどう扱われるか |
| 利用資格・年齢 | 誰が使えるサービスとして定められているか |
| 教育機関向けの特約 | 一般向け規約とは別に、教育向けの条件が定められていないか |
| 解約・削除 | 削除の可否と手順が書かれているか |

英文の規約なら、"train"、"improve our services"、"opt out" といった語でページ内検索すると、利用目的とオプトアウトの条項に早く届きます。日本語では「サービスの改善」「品質向上」という言い回しが学習利用を含むことがあるため、その前後を読みます。

探しても、学習利用や保存先について明確な記載が見つからないことがあります。その場合、記載が無いこと自体が判定材料です。「書いていないから大丈夫」ではなく「書いていないから確認が必要」と扱い、判定は保留にして、事業者への問い合わせか、候補から外す判断につなげます。

見つけた条項を誰にどう渡すかは、[無料ICTツールを授業で使う前の確認手順](/articles/free-ict-tools-safety-checklist)の Gate 1 に手順があります。条文の意味が取りにくいときも、その条項だけを絞って持ち込めば足ります。

## AIサービス一次判定シート（本サイト作成の参考様式）

> **本サイト作成の参考様式です。** 文部科学省・教育委員会等が定める公式様式ではありません。所属校・設置者に定められた様式や申請書がある場合は、そちらに従ってください。

A4一枚に収まる分量です。空欄を残したまま「候補にする」を選ばないことが、この様式の使い方のすべてです。

| 記入欄 | 書くこと | 記入 |
|---|---|---|
| サービス名 | 正式名称。提供事業者名も併記する |  |
| URL | 規約・ポリシーのページも控える |  |
| 確認した日 | 規約を読んだ日。判定はこの日の情報に基づく |  |
| 記入者 | 言い出した本人の氏名 |  |
| 使いたい場面 | どの業務・どの授業で、何をさせたいか |  |
| 利用主体 | 教員のみ／児童生徒も使う |  |
| 契約主体 | 個人／学校／設置者のどれになるか |  |
| 年齢要件と保護者同意 | 規約上の年齢条件と、同意が要るかどうか |  |
| アカウント方式 | 学校アカウント連携／個人アカウント登録 |  |
| 入力する予定のデータ | 具体的に。個人情報を含むかどうかを明記 |  |
| 保存先と保持期間 | 国・法域と、保存される期間 |  |
| 二次利用と既定値 | 学習に使われるか。初期設定はオンかオフか |  |
| オプトアウト | 可否・設定の場所・管理者が一括適用できるか |  |
| 第三者提供 | 有無と、提供先の範囲 |  |
| 削除の可否と手順 | 個別データとアカウント削除後の扱い |  |
| 生成物の権利と責任 | 配布・公開の条件と、誤りの責任の所在 |  |
| プランの差 | 無料プランと、実際に使うプランの条件の違い |  |
| 校内の承認経路 | 次に相談する相手と、相談予定日 |  |
| 判定 | 候補にする／保留／候補にしない |  |
| 保留の理由 | 何が分かれば判断できるか |  |
| 再検討予定日 | いつ、誰が、何を確かめて再開するか |  |

### 判定を3値にする理由

候補にする・候補にしないの2値にすると、確かめきれなかった項目が「とりあえず使ってみて考える」に流れます。保留という置き場所を用意し、そこに「何が分かれば判断できるか」と「再検討予定日」の2欄を必ず添えることで、判断を先送りにするのではなく、判断を待つ状態として管理できます。

次のどれかに当てはまるうちは、候補にするへ進みません。

- 実際に使うプランの規約を読んでいない（無料トライアルの条件だけで判断しようとしている）
- 二次利用の既定値が分からない、または管理者側で一括して変えられるかが分からない
- 入力する予定のデータに、入力してよいか判断が済んでいない個人情報が含まれている
- 契約主体と管理者を誰にするかが決まっていない

3つ目に当たったときは、シートを止めて[学校の校務で生成AIを使う前の判断ガイド](/articles/ai-koomu-kaizen-nyumon)の校務ゲート2へ戻ります。候補にしないという判定も成果です。理由を1行残しておけば、同じ案内が次に届いたときに一次判定をやり直さずに済みます。

## 記入例（完全な架空の事例）

> 以下は説明のための完全な架空の例です。サービス名・学校・人物はすべて架空で、実在のものとは関係ありません。

| 記入欄 | 記入例 |
|---|---|
| サービス名 | ワークシート作成AI「サンプルAI」（架空のサービス） |
| URL | 事業者サイトと利用規約・プライバシーポリシーの3件を控えた |
| 確認した日 | ◯年◯月◯日 |
| 記入者 | 第3学年担任 |
| 使いたい場面 | 算数の習熟度別プリントのたたき台を作る |
| 利用主体 | 教員のみ。児童は使わない |
| 契約主体 | 未定。無料プランは個人登録のみと書かれている |
| 年齢要件と保護者同意 | 18歳以上。児童が使わないため、今回は該当しない |
| アカウント方式 | 無料プランは個人アカウントのみ。学校アカウント連携は上位プランの記載あり |
| 入力する予定のデータ | 単元名と問題の傾向のみ。児童の氏名・成績は入力しない |
| 保存先と保持期間 | 保存先の国の記載が見つからない。保持期間は「必要な期間」とのみ記載 |
| 二次利用と既定値 | 無料プランは「サービスの改善のために利用」と記載。既定はオン |
| オプトアウト | 設定画面から個人単位で可。管理者による一括適用の記載は見つからない |
| 第三者提供 | 業務委託先への提供の記載あり。提供先の範囲は明示されていない |
| 削除の可否と手順 | 個別データの削除は可。アカウント削除後の扱いの記載は見つからない |
| 生成物の権利と責任 | 生成物は利用者に帰属、校内配布は可と読める。正確性の保証はしないと明記 |
| プランの差 | 学校向けプランの案内はあるが、二次利用の扱いの記載が見つからない |
| 校内の承認経路 | 次は情報主任へ。◯月◯日の校内研の後に相談予定 |
| 判定 | 保留 |
| 保留の理由 | 学校向けプランで二次利用の既定値がオフになるか、管理者が一括設定できるか、保存先の国はどこか |
| 再検討予定日 | 事業者へ問い合わせた回答が届き次第。目安は2週間後 |

この例では、機能そのものへの評価とは別に、既定値と保存先の記載が見つからないという1点で判定が止まっています。止まった理由と再開の条件が書いてあるので、回答が届けば、同じ欄を埋め直すだけで判定を再開できます。使い心地だけで先に決めてしまうと、この欄は最後まで空のまま残ります。

## このシートで決まらないこと

- **一次判定は導入の可否ではありません。** 候補にするという判定は、確認経路に進んでよいという意味だけを持ちます。
- **学校・設置者によって、判定の基準も承認経路も異なります。** 自校の定めが優先します。
- **サービスの仕様と規約は変わります。** 判定は確認した日の情報に基づくものです。継続して使う場合は、確認日を更新しながら見直してください。
- **法的判断の代替ではありません。** ある入力が個人情報保護法上どう扱われるか、生成物の利用が著作権法上どう扱われるかは、設置者・所管部署に確認してください。
- **特定のサービスを推奨・保証するものではありません。**
- 掲載したシートは本サイト作成の参考様式であり、公式様式や申請書ではありません。
