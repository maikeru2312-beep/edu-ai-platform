## はじめに

学期末が近づくと、成績処理や指導要録の準備と並行して、クラス全員分の所見が待っています。1人あたり15分で書けたとしても、35人なら9時間近く。しかも書き進めるほど「意欲的に取り組みました」「積極的に発言できました」と同じ言い回しばかりが浮かび、後半の子ほど文章が薄くなっていく——所見作成のつらさは、時間だけでなくこの「表現の枯渇」にもあります。

そこでChatGPTを開いてみたものの、手元のメモを貼り付ける手前で「これは入力していいのか」と指が止まる——この迷いは正しい感覚です。所見の材料は児童生徒の行動記録そのもの、つまり個人情報のかたまりです。メモをそのまま貼り付ければ、外部サービスへの個人情報送信になります。生成AIは「書き出せない」「言い回しが尽きた」という部分でたたき台として使える場合がある一方で、校務でのAI活用のなかでも、所見は便利さとリスクがもっとも近い距離にある業務です。

本記事では、その迷いを「使わない理由」で終わらせず「何を判断すれば使えるか」に変えるために、匿名化の具体的な手順、プロンプト例、校内で誰に・何を・どの順で確認するか、提出前のチェックリストまで、安全に使うための道筋を教員の立場から解説します。

> 本記事は一般的な活用方法の紹介です。AIツールの利用については、**所属校・教育委員会のガイドライン・方針を必ず確認の上**、自己判断・自己責任で行ってください。

## 1. ChatGPTで所見作成を効率化できる理由

通知表所見は、一定のパターンと文体を持つ文章です。

- 観点（学習・行動・成長など）ごとの記述
- 前向きな言葉づかいと丁寧な文体
- 60〜120字程度の決まった文字数

このように**構造が決まっている文章の下書き生成**は、生成AIが特に得意とする作業です。教員が観点やキーワードを入力すれば、下書きとなる文章を瞬時に出力してくれます。

ただし、**AIはあくまで下書きを補助するツール**です。最終的な内容の判断・修正・確認は必ず教員が行います。「AIが所見を書く」のではなく、「教員がAIの助けを借りて所見を仕上げる」という位置付けが正しい理解です。

匿名化、事実確認、校内決裁を省いてはいけないため、AI利用が必ず時間短縮になるとは限りません。本記事ではAIを「所見を自動作成するもの」ではなく、個人を識別できない素材から言い換え候補を得る補助として扱います。

## 2. 通知表所見作成でAIを使うときの基本姿勢

所見作成にAIを使う前に、以下の姿勢を確認してください。

**✅ やること**
- 入力前に個人情報を取り除く（匿名化・抽象化）
- 出力された文章を必ず読んで確認・修正する
- 事実と異なる表現が含まれていないか照合する
- 所属校・教育委員会の方針を事前に確認する

**❌ やらないこと**
- 児童生徒の氏名・学籍番号をAIに入力する
- 病名・障害名・家庭環境などの要配慮情報を入力する
- 生成された文章をそのままコピーして使用する
- 学校支給端末以外の環境でのAI利用（ルール次第）

この2つを守るだけで、リスクを大幅に下げることができます。本サイトでは、この「入力前に削る・出力後に照合する」の二段構えを、校務でAIを使うときの最低ラインと考えています。どちらか一方だけでは足りません。

## 3. 児童生徒の個人情報をそのまま入力してはいけない理由

ChatGPTをはじめとするAIサービスは、入力した内容がサービス提供企業のサーバーに送信されます。

**個人情報を入力することによるリスク：**

1. **情報漏洩リスク** — 入力データがどのように管理・利用されるかはサービスごとに異なります
2. **個人情報保護法への抵触** — 要配慮個人情報（障害・病歴など）の第三者提供には本人同意が必要です
3. **校内規定・教育委員会方針への違反** — 多くの教育委員会は個人情報の外部サービス入力を禁じています
4. **保護者・地域からの信頼失墜** — 万が一の情報漏洩は保護者・地域の信頼に直結します

学校現場では「他の先生も使っているから」が事実上の許可のように扱われがちですが、何かあったときに責任の所在が曖昧になるのはこのパターンです。「無料ツールだから大丈夫」「匿名化しているつもり」という判断ではなく、**所属校の情報主任・管理職に確認してから使い始める**ことが基本です。

## 4. 安全な使い方：4つの原則

### 原則① 匿名化する

入力する前に、児童生徒が特定できる情報をすべて取り除きます。

| 入力してはいけない情報 | 代わりに使う表現 |
|---|---|
| ○○さん（氏名） | 「この子ども」「担当児童」 |
| A組の男子 | 「小学○年生の児童」 |
| 自閉スペクトラム症 | 「コミュニケーションに支援が必要な児童」 |
| 家庭が複雑な子 | （入力しない） |

### 原則② 観点・事実だけを入力する

「この子はこういう子」という評価ではなく、**観点・行動・成長の事実**だけを入力します。

**例：**
> × 「消極的でなかなか発言できない子です」  
> ○ 「授業中の挙手発言が少ないが、グループ活動では積極的に意見を伝える場面が見られた」

### 原則③ 事実情報を抽象化する

具体的なエピソードも、特定の児童が識別できない程度に抽象化します。

> × 「運動会のリレーで転んでも最後まで走りきった」  
> ○ 「困難な場面でも最後まで粘り強く取り組んだ」

### 原則④ 最終判断は必ず教員が行う

生成された文章は**必ず読み直し、事実と照合**します。AIは文章として自然な表現を生成しますが、「その子の実態に合っているか」の判断は教員にしかできません。

## 5. AIに任せてよいのは「表現」まで。「評価」は教師が引き受ける

クラス全員分の所見にAIを使う必要はありません。使う・使わないの判断軸として、次の3つを目安にしてください。

**① 匿名化しても意味が変わらないか**

「係活動に責任をもって取り組んだ」のような行動事実は、匿名化しても情報が失われません。一方、その子固有の事情（転入直後の適応、長期欠席からの復帰など）が所見の核心になる場合、匿名化した時点で文章の骨組み自体が成り立たなくなります。匿名化で骨組みが崩れる所見は、最初から自分で書いたほうが早く、安全です。

**② 保護者との関係に配慮が必要な子ではないか**

学期中にトラブルがあった、指導方針について保護者から要望が続いている——そうした子の所見は、一語一語の選び方が信頼関係に直結します。AIの生成文をベースにすると、微妙なニュアンスの検討がどうしても浅くなります。この種の所見こそ、時間をかけて自分の言葉で書くことをお勧めします。

**③ 書けない理由は「時間」か「材料」か**

行動のメモは手元にあるのに文章にならない、という場合はAIが役立ちます。逆に、そもそもその子について書ける材料が思い浮かばないなら、必要なのはAIではなく日々の記録の見直しです。AIは観察の不足を埋めてはくれません。材料が薄いままAIに頼ると、誰にでも当てはまる無難な所見が量産されるだけです。本サイトでは、所見の質を最終的に決めるのは生成AIの性能ではなく、学期中に積んだメモの質だと考えています。

## 6. プロンプト例

### ケース①：よい点を膨らませたい

```
以下の観点をもとに、小学校通知表の所見文（80字以内）を作成してください。

・観点：算数の授業態度と理解
・事実：計算問題に粘り強く取り組む。友達に教える場面も見られた
・方向性：意欲と協力の姿勢を前向きに表現する
```

### ケース②：課題を前向きに表現したい

```
以下の観点をもとに、通知表所見（80字以内）を作成してください。
課題を直接指摘せず、「次の目標」や「成長の途中」として前向きに表現してください。

・観点：国語の書く活動
・事実：文章を書くことへの苦手意識がある。短い文は書ける
・方向性：できていることを認め、次のステップを示す
```

### ケース③：短いメモから所見文を作りたい

```
以下のメモをもとに、保護者に伝わる通知表所見（80字以内）を作成してください。
主語は「〇〇さん」ではなく「友達と」「学習では」のように書き出してください。

メモ：体育得意・給食委員で活躍・授業は静かに参加・係活動まじめ
```

### ケース④：特別支援教育での配慮ある表現に直したい

```
以下の所見文を、特別支援教育における配慮表現に修正してください。
「できない」「苦手」という表現を使わず、成長・支援・次の目標につながる言葉にしてください。

修正前：「漢字の書き取りが苦手で、テストでミスが多い」
```

**出力例のイメージ：**
> 「漢字の練習に丁寧に取り組んでいます。書き順を意識する場面が増えてきており、引き続き繰り返し練習を通じて定着を図っていきます。」

## 7. 生成文の「もっともらしさ」を信用しない

AIの生成する文章には、次のような問題が含まれる場合があります。

| 問題 | 具体例 |
|---|---|
| **事実と異なる内容** | 実際には見られていない行動が書かれる |
| **過度な称賛** | 実態以上にポジティブな評価になる |
| **画一的な表現** | クラス全員の所見が似通った文体になる |
| **保護者に違和感を与える表現** | 機械的・他人行儀な文体になる場合がある |
| **ハルシネーション** | もっともらしいが実際にはない事実を生成する |

所見は子どもの学びや成長を保護者に伝える大切な文章です。AIの出力をそのまま使うのではなく、**教員の言葉でひと手間加えることが信頼性を守ります**。

## 8. 校内で確認する順番：誰に・何を聞くか

生成AIの校務利用のルールは、2026年現在も自治体・学校によって差があります。「他の先生も使っているから大丈夫」ではなく、次の順番で確認しておくと、後からの指摘や手戻りを防げます。

1. **自治体・教育委員会のガイドラインを自分で読む** — 「生成AI」「外部サービス」「個人情報」に関する項目を探します。校務利用に触れていない文書も多く、その場合は次のステップで判断を仰ぎます。
2. **情報主任・ICT担当に聞く** — 学校支給端末での利用可否、使ってよいサービスやアカウントの範囲は、実務を知る担当者に聞くのが早道です。
3. **教頭（管理職）に一言入れる** — 「所見の下書きに、個人情報を入れない形で生成AIを使いたい」と具体的に伝えます。漠然と「AIを使っていいですか」と聞くと判断が保留されがちです。何を入力し、何を入力しないかまでセットで説明できると、話が前に進みやすくなります。
4. **学年内で共有する** — 学年で所見の書き方をそろえている学校では、自分だけ文体が変わると目立ちます。学年主任にも一言伝えておくと安心です。

確認が取れたら、**いつ・誰に・何を確認したかを簡単にメモで残しておく**ことをお勧めします。年度途中で方針が変わることもあるためです。

### 文科省ガイドラインのどこを読むか

一次情報として押さえておきたいのが、文部科学省「初等中等教育段階における生成AIの利活用に関するガイドライン（Ver.2.0）」です。「所見」という言葉は本文に出てきませんが、読むべき場所は決まっています。

- **校務での利活用に関する記述** — 生成AIを教職員の業務負担軽減に活用する方向性が示されています。「校務で使うこと自体が不適切」ではない、という前提をここで確認できます。
- **個人情報・プライバシーに関する記述** — 個人情報を入力しない運用の必要性が繰り返し強調されています。所見作成は、まさにこの部分が核心になる業務です。

ガイドラインは「使ってよい／悪い」の二択を示す文書ではなく、「何に注意すれば使えるか」を整理した文書です。管理職に相談する際も「ガイドラインではこう整理されています」と示せると、話が具体的になります。原文の読み解き方は[文科省の生成AIガイドライン（Ver.2.0）を学校現場の視点で読む](/articles/generative-ai-guideline-v2-school-reading)で詳しく解説しています。

## 9. よくある失敗例

### 失敗例① 氏名をそのまま入力した

> 「○○くんの所見を書いて」と入力してしまった

→ 外部サービスへの個人情報送信になります。氏名は必ず取り除いてください。

### 失敗例② 生成文をクラス全員に流用した

> 同じプロンプトで生成した文章を、表現を少し変えて全員に使った

→ 保護者が読んで不自然に感じたり、他の家庭と似た所見であることに気づかれることがあります。必ずその子どものエピソードを反映して修正を加えてください。

### 失敗例③ 病名・診断名を入力した

> 「ADHD傾向のある児童の所見を」と入力した

→ 診断名・障害名は要配慮個人情報です。診断名を使わず「集中を保つことが難しい場面がある児童」など行動の事実で入力してください。

### 失敗例④ 確認せずに印刷した

> 生成された文章を確認せずにそのまま通知表に貼り付けた

→ AIは事実と異なる内容を自信満々に出力することがあります（ハルシネーション）。必ず一字一句確認してから使用してください。

### 失敗例⑤ 学級全員分を一気に生成して、直前に破綻した

> 提出3日前に全員分のメモをまとめて処理しようとした

→ AI活用でも、匿名化・生成・照合・修正の工程には1人あたり数分かかります。まとめて処理すると照合が雑になり、事実と違う所見を見逃しやすくなります。日々のメモが溜まった時点で数人分ずつ進めるほうが、結果的に安全で速い方法です。

## 10. 提出前チェックリスト

所見でのAI活用は、「入力前」と「提出前」の2回のチェックで安全性が決まります。特に特別支援学級・通級の所見は、氏名を消しても支援内容や配慮の記述の組み合わせから個人が推測されやすいことを見落とさないでください。印刷・提出の前に、次の項目を確認してください。

**入力前**

- [ ] 氏名・出席番号・学級名を取り除いた
- [ ] 診断名・障害名を行動の事実に置き換えた（要配慮個人情報は「匿名化すれば入力できる情報」ではなく、そもそも入力しない情報です）
- [ ] 家庭状況・成績・指導記録の詳細を含めていない
- [ ] 校内での利用確認（情報主任・管理職）が済んでいる

**提出前**

- [ ] 書かれている行動・エピソードが事実と一致している
- [ ] その子を知らない人が書いたような、一般的すぎる文章になっていない
- [ ] 近い観点で書いた他の子の所見と、言い回しが重複していない（AI生成文は語彙が似通いやすく、きょうだいや近所で見せ合う保護者ほど気づきます）
- [ ] 学校の様式（字数・文体・書き出しのルール）に合っている
- [ ] 「できない」「苦手」など、所見にふさわしくない表現が残っていない

## まとめ

ChatGPTによる通知表所見の下書き作成は、表現候補を検討する補助になり得ます。ただし、時間短縮や品質向上を保証するものではなく、次の点を守る必要があります。

1. **個人情報（氏名・診断名・家庭情報）は入力しない**
2. **生成された文章はそのまま使わず、必ず確認・修正する**
3. **所属校・教育委員会の方針を事前に確認する**
4. **最終判断は常に教員が行う**

そして迷ったときの原則はひとつです。匿名化すると意味が崩れる所見、保護者対応に配慮が必要な所見は、AIを通さず自分の言葉で書く。「AIに所見を書いてもらう」のではなく、「AIで表現の詰まりを解消し、子どもと向き合う時間を確保する」という視点で活用しましょう。
