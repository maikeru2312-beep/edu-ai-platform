## はじめに

特別支援教育の現場には、さまざまなICT支援ツールが登場しています。見通しを示すタイマーアプリ、文字を音声で読み上げるツール、コミュニケーションを助けるAACアプリ——それ自体は使いやすくできていても、「どれを選べばよいのか」「子どもに合っているのか」という判断に迷う教員は少なくありません。

ICT支援ツールを選ぶ基準は、「便利そうかどうか」ではありません。**子どもが何に困っているのか、何ができるようになりたいのか**、その目的から逆算して選ぶことが出発点です。

本記事では、ICT支援ツールを目的別に整理し、授業での使い方と導入前に確認しておきたいことをまとめます。

> 本記事は一般的な情報提供を目的としています。具体的な支援方針・ツール導入の判断は、本人・保護者・関係機関と連携の上、**所属校・教育委員会の方針に従って**進めてください。個別の医療的・診断的判断を代行するものではありません。

→ 合理的配慮として位置づけるか、指導の手立てとするかの整理は[特別支援教育におけるICT活用と合理的配慮](/articles/special-needs-ict-reasonable-accommodation)で扱っています。

## ICT支援ツールを選ぶ前に確認したいこと

ツールを探し始める前に、次の問いを整理しておくと選択の軸がぶれにくくなります。

### 子どもが何に困っているのか

「使えそうなツール」より先に、「今、何が難しくて、授業への参加が制限されているのか」を具体的に把握することが最初の一歩です。

困りごとの例：

- 言葉で意思を伝えることが難しい
- 文字を読むことに時間がかかる
- 授業の流れが読めず、次に何をすればよいかわからなくなる
- 手書きで文字を書くことに強いストレスがある
- 感覚の調整が難しく、集中を保てない時間がある

### 何をできるようにしたいのか

「この子をICTで支援したい」という気持ちだけでは、目的が曖昧になります。「**授業への参加」「自分の考えの表現」「理解の確認」「見通しを持った行動」「他者とのコミュニケーション**」など、目的を分けて考えるとツールの候補が絞りやすくなります。

## 目的別のICT支援ツールの考え方

### 1. 見通し支援

「次に何があるのか」「あとどれくらいで終わるのか」が分かることは、見通しを持つことが難しい子どもにとって大きな安心につながります。

考え方：

- タイマー表示や視覚的なカウントダウンは、「時間の流れ」を見える形にする
- 1日の流れや授業の手順を写真・アイコン・文字で示すスケジュール表示は、行動の見通しを支える
- 「終わった活動」を消す・裏返すといった操作が自分でできると、達成感にもつながる

注意点：ツールを使うことでかえって画面に注意が向きすぎることもあります。紙のスケジュール表や具体物と組み合わせて使う方法も有効です。

→ 視覚スケジュールの活用については[特別支援教育における見通し支援：スケジュール・手順表・視覚支援の使い方](/articles/special-needs-visual-schedule-support)もご参照ください。

### 2. コミュニケーション支援（AAC）

言葉による表現が難しい子どもが、自分の意思・気持ち・要求を伝えるための手段を広げることがAACの目的です。ICTはその選択肢の一つです。

考え方：

- 声で伝えることが難しい場面で、伝える手段そのものの選択肢を増やすために使う（手段ごとの型の違いは後述の「AACは伝え方の型で分けて考える」で扱います）
- 子どもが自分で選んで操作できる画面設計かを確認する

注意点：AACはあくまで「伝える手段の選択肢を広げる」ためのものです。「言葉を使わなくなる」という懸念はよく挙がりますが、AACを使うことで言語表現が抑制されるという根拠はありません。子どもの実態に合わせて、言語指導や他の支援と組み合わせて使います。

→ 校内での位置づけ・合意・記録の進め方は[特別支援教育におけるICT活用と合理的配慮](/articles/special-needs-ict-reasonable-accommodation)をご参照ください。

### 3. 読み書き支援

文字の読み書きに困難がある子どもに対しては、ICTが「別の方法で読む・書く」手段を提供できます。

考え方：

- テキスト読み上げ機能は、文字を視覚的に読むことが難しい場合に音声で情報を受け取る手段になる
- 音声入力・スキャンなどの入力補助は、手書きが難しい場合に「書く」手段を広げる
- ふりがな表示、フォントサイズ変更、文字間隔の調整など、読みやすさに関わる設定が変更できるかを確認する
- 文字変換候補の表示など、スペルや文字の想起が難しい場合を支える入力支援機能もある

注意点：読み書き支援ツールは「読み書きの練習をしなくてよい」ということではありません。何の目的で使うかを明確にし、他の学習活動と切り分けて使います。

### 4. 記録・振り返り支援

学習記録や自己評価を積み重ねることが難しい場面でも、ICTが記録の負担を下げる役割を果たせます。

考え方：

- 写真・動画・音声での記録は、文字での記録が難しい子どもが「やったこと・できたこと」を残す方法になる
- ポートフォリオ的に記録を蓄積することで、本人・保護者・関係教員が変化を確認しやすくなる
- 日々の気持ちや体調の記録（体調チェック・感情のセルフモニタリング）を視覚的に入力できるツールもある

注意点：記録に使った写真や音声には個人情報が含まれます。保存先・共有範囲・管理方法について、校内ルールと保護者への説明を事前に整理しておく必要があります。

→ 記録や写真を外部サービスへ入力してよいかの線引きは[学校の校務で生成AIを使う前の判断ガイド](/articles/ai-koomu-kaizen-nyumon)の Gate 2 で扱っています。

### 5. 感覚・注意の調整支援

感覚の過敏さや注意の持続に困難がある場合、ICTは環境調整の一部として機能することがあります。

考え方：

- ノイズキャンセリング機能付きヘッドホンやイヤーマフは、聴覚的な刺激を調整する補助具として使われる
- 集中しやすい画面表示（余計な情報を減らす、背景色を変える）を設定できるツールもある
- 一定時間ごとに休憩を促す機能や、視覚的なポーズのタイミング提示を活用する方法もある

注意点：感覚の特性は子どもによって大きく異なります。「このツールを使えばよい」という決まった答えはなく、個別の実態を確認しながら試行・調整していくことが基本です。医療的な判断が必要な場面では、専門機関と連携して進めます。

### 6. 教員の教材準備支援

ICT支援ツールは、子どもが使うだけでなく、教員が教材を準備したり支援計画を整理したりする場面でも活用できます。

考え方：

- 個別の指導計画（IEP）の文書作成を効率化する書式ツールやテンプレートの活用
- 視覚支援教材（スケジュール表・絵カード・課題指示）のデジタル作成・印刷
- 校内での情報共有や引き継ぎをシンプルにまとめる記録ツールの活用

注意点：教材準備でAI生成ツールを使う場合、児童生徒の個人情報（名前・成績・特性）を入力しないことが原則です。

→ 教材準備に生成AIを使う場合の判断手順は[学校の校務で生成AIを使う前の判断ガイド](/articles/ai-koomu-kaizen-nyumon)をご覧ください。

| 目的 | 主な活用場面 | 確認したい観点 |
|---|---|---|
| 見通し支援 | タイマー・スケジュール表示 | 子どもが自分で操作できるか、終了が分かりやすいか |
| コミュニケーション支援 | 意思表示・要求伝達 | 語彙・操作方法が子どもの実態に合っているか |

## 製品名ではなく機能で候補を絞る

目的が整理できたら、製品名を探す前に、その働きをする機能が手元の端末にすでにないかを見ておきます。読み上げや音声入力のように、専用のアプリを入れなくても標準機能として使えるものがあるためです。標準機能で足りる場合は、導入の手続きも、更新や管理の負担も小さく済みます。

### 端末の標準機能から確かめる

読み上げ・音声入力のほかに、次のような機能が端末に最初から用意されていることがあります。

- 動画や音声に字幕を表示する機能。音声だけでは聞き取りにくい場面で、文字と音声の両方から内容を受け取れるようにする
- 画面のタッチやボタン操作が難しい場合の、操作そのものを置き換える設定。スイッチによる操作、押す・長押しの受け付け方の調整など
- 使うアプリや操作できる範囲を一時的に限定する設定。画面上で触れられる対象を減らし、活動から離れにくくする

機能の名称、設定画面のたどり方、そもそも使えるかどうかは、OSの種類・端末の世代・設置者の管理設定によって変わります。ここで挙げたのは機能の働きであって、同じ名前の項目が手元の端末にあるとは限りません。紹介記事の名称で探すより、実際の端末の設定画面を開いて確かめ、管理設定で制限されている場合は校内の情報担当に相談するほうが確実です。

設定を変えたときは、いつ・どの設定を・どう変えたかを短く残しておきます。合わなかったときに元へ戻せますし、担当が替わったあとも同じ状態を再現できます。共用の端末では、他の子どもの使用に影響しないかもあわせて確認します。

### AACは伝え方の型で分けて考える

AAC（拡大代替コミュニケーション）は、話し言葉だけに頼らずに意思を伝える手段の総称で、特定のアプリを指す言葉ではありません。候補を比べるときは伝え方の型で分けると、本人に求められることの違いが見えやすくなります。

| 伝え方の型 | 本人が行うこと | 確かめたいこと |
|---|---|---|
| 絵・写真・シンボルから選ぶ | 選択肢の中から選んで示す | 語彙の数と並び方が本人に合っているか |
| 文字を入力して音声で出す | 文字を打つ、または候補から選ぶ | 入力の負担が、伝えたい内容に見合っているか |
| 録音した音声を再生する | ボタンを押す | 用意した以外のことを伝えたい場面をどう補うか |
| 紙の絵カードを画面に置き換える | これまでと同じ選び方をする | 紙で成り立っていた手順が画面上でも保てるか |

型は候補を絞るための入口であり、これだけで決まるものではありません。AACの選定・調整は、言語聴覚士などの専門職や保護者と相談しながら進めることが前提です。校内だけで結論を出さず、専門職に相談することを前提に候補を絞る、という順序にしておきます。

## 授業で使うときの注意点

### 使う時間・場面を決める

「授業全体でずっと使う」のではなく、「この活動のこの部分で使う」と場面を絞る方が、子どもも教員も混乱しにくくなります。いつ使い、いつしまうかを事前に決めておきましょう。

### 子どもが自分で選べる余地を残す

支援ツールを「使わせる」のではなく、子ども自身が「使うかどうか」「どう使うか」を選べる環境が理想です。初めから全員・全場面で使わせるより、「必要な時に自分で取り出す」運用が子どもの主体性を育てます。

### 紙や具体物と組み合わせる

ICTはあくまで選択肢の一つです。紙のスケジュール表、絵カード、実物、板書など、ICT以外の方法とうまく組み合わせることで、子どもが様々な場面で対応できる力がつきます。ICT依存を避けるためにも、デジタルとアナログを意識的に使い分けましょう。

### 操作練習だけで終わらせない

「アプリを操作できるようになること」が目標ではありません。ツールを使って何ができるようになるかが学習のゴールです。操作に慣れた後は、ツールを使って本来の学習活動に向かっているかを確認します。

### 個人情報・写真の管理に注意する

記録に使った写真・動画・音声には個人情報が含まれます。端末の管理場所、外部への送信・共有、データ削除のタイミング、保護者への説明など、学校のルールと照らし合わせて運用してください。

→ GIGAスクール端末の管理・運用に関する観点は[GIGAスクール端末を授業で活かす基本](/articles/giga-device-lesson-use-guide)もご参照ください。

## 授業での注意点まとめ

| 注意点 | 具体的に確認すること |
|---|---|
| 使う場面を絞る | いつ使い始め、いつしまうかを事前に設定しているか |
| 子どもの選択を大切に | 子どもが「使うかどうか」を自分で判断できる運用になっているか |
| 紙・具体物と組み合わせる | ICTだけに依存せず、他の方法も選べるようにしているか |
| 目的を忘れない | 操作できるようになることではなく、学習参加が広がっているかを確認しているか |
| 個人情報の管理 | 写真・音声記録の保存・共有・削除のルールが整理されているか |

## 支援ツール選定チェックリスト

ICT支援ツールを導入・継続する前に、以下の観点を確認しておくと、導入後のトラブルや使い続けられない事態を防ぎやすくなります。

### 目的の明確さ

- [ ] 「何に困っているか」を具体的に把握しているか
- [ ] 「何ができるようになりたいか」が明確か
- [ ] ツールを使うことが目標になっていないか

### 子どもとのマッチング

- [ ] 子ども自身が操作できるか（または支援があれば使えるか）
- [ ] 子どもがそのツールを使うことに抵抗感はないか
- [ ] 子どもの発達段階・感覚特性に合っているか

一度選んだツールでも、次のような場合は選択をいったん見直します。特定の製品を良し悪しで断じるためではなく、目の前の子どもに合っているかを確かめるための観点です。

- **操作負担が大きい**：設定や操作に手間がかかり、本来の活動より操作に時間を取られてしまう
- **目的に合わない**：解決したい困難や支援の目的と、ツールでできることがずれている
- **本人が使いにくい**：本人が使いづらさや抵抗を示す、または実際にはあまり使われていない

### 継続・引き継ぎ可能性

- [ ] 担当教員が準備・更新を継続できるか
- [ ] 学年をまたいで引き継ぎができる仕様か
- [ ] 家庭でも共有・連携できる必要があるか、保護者への説明をしているか

### 安全・管理

- [ ] 個人情報（写真・音声・記録）の保存先・管理方法が明確か
- [ ] 外部サービスへのデータ送信について学校のルールを確認しているか
- [ ] 導入・更新に際して管理職・情報担当と確認済みか

## 候補を比べて決めるときの手順

ここまでは「何のために使うか」を整理する段階でした。候補が複数出てきたあとは、比べ方そのものを決めておかないと、機能の多さや評判で決まってしまいます。

### 使ってよいかの確認と、本人に合うかの判断を分ける

判断には性質の違う二つが混ざっています。一つは、そのサービスを学校として使ってよい状態かという前提の確認です。もう一つは、目の前の子どもに合っているかという支援上の判断です。

前提の確認は、支援の目的とは無関係に、満たしていなければそこで止まります。学校・設置者のルール、児童生徒のアカウントの要否、外部へ出る情報、公開・共有機能、終わるときの回収と削除といった観点です。この手順は[無料ICTツールを授業で使う前の確認手順](/articles/free-ict-tools-safety-checklist)が扱っているため、本記事では前提が通った候補を比べる側に絞ります。

順番を逆にしないことが要点です。本人に合いそうな候補を一つに絞り込んでから前提の確認で止まると、支援の見通しごと組み直すことになります。

### 困難さの名前ではなく、参加できない場面から候補を出す

「読みに困難があるから読み上げ」「発語がないからAAC」というように、困難さの名前とツールを一対一で結びつけると、候補が最初から一つに固定されます。確かめたいのは、その子がどの場面で参加できなくなっているのか、その場面に何があれば参加できるのか、です。同じ読みの困難でも、教科書の本文を追う場面と、板書を書き写す場面とでは、必要になる機能が違います。

候補を出す前に、端末に最初から入っている機能で足りるかどうかも確かめます。OS（Windows、iPadOS、ChromeOSなど）には、読み上げ、拡大、文字サイズや配色の変更などの機能が標準で用意されています。標準機能で足りる場合は、申請も費用も引き継ぎも発生しません。アプリを追加する場合は、そのアプリがOS標準の読み上げや拡大と干渉せずに動くかどうかを、試用の段階で確認します。

### 支援手段が途中で止まらないかを確かめる

支援ツールは、その子の表出や理解の手段そのものになっていることがあります。教科の教材が一時的に使えないのとは、止まったときの意味が違います。候補の段階で次の三つを確認しておきます。

- 通信が不安定なときや校内ネットワークが止まったときに、最低限の機能が使えるか
- 使えない日にどうするか（紙のカード、具体物、教員が読み上げるなど）を決めてあるか
- 提供が終了したときや仕様が変わったときに、作り込んだ内容を持ち出せるか

三つ目は見落としやすい点です。AACの語彙やシンボルの並び、スケジュールに使った写真、記録の蓄積は、その子に合わせて調整を重ねたものです。書き出し（エクスポート）ができない仕様だと、乗り換えのたびに作り直しになります。

### 候補比較シート

候補が二つ以上ある段階では、次の軸を並べて比べます。点数をつけて合計で決めるための表ではなく、空欄を残さないための表です。確認できていない欄は空欄のままにせず「要確認」と書き、誰に聞けば分かるかまで記録します。

| 確認軸 | 候補A | 候補B | 確認する相手・資料 |
|---|---|---|---|
| 参加できていない場面と、そこでの目的 |  |  | 個別の指導計画、授業の記録 |
| その場面で必要になる機能 |  |  | 公式の機能説明 |
| 本人が自分で操作できたか |  |  | 試用時の本人の様子 |
| 本人が使うことに抵抗を示さなかったか |  |  | 試用時の本人の様子、本人への確認 |
| OS標準機能との干渉の有無 |  |  | 試用時の動作、公式ヘルプ |
| 通信が使えないときの動作と代替手段 |  |  | 試用時の動作、授業の計画 |
| 作った内容の書き出し可否 |  |  | 公式ヘルプ |
| 準備・更新を続けられる負担か |  |  | 担当者間の相談 |
| 次年度・他の教員へ引き継げるか |  |  | 担当者間の相談 |
| 前提の確認が済んでいるか |  |  | 管理職、情報担当、設置者 |
| 見直す日 |  |  | 担当者間の記録 |

最後の「見直す日」は、選ぶ時点で決めておく欄です。合うかどうかは使ってみないと分からないため、いつ確認し直すかを先に置いておかないと、合わないまま続くか、いつの間にか使われなくなるかのどちらかになりやすくなります。

記入例（架空）：朝の会で次の活動を確認する場面を想定した、実在しない例です。候補Aを写真を並べるスケジュールアプリ、候補Bを端末に標準で入っているカレンダー機能とします。「本人が自分で操作できたか」は、候補Aが「終わった項目を自分でタップできた」、候補Bが「項目の追加に教員の操作が必要だった」。「通信が使えないときの動作」は、候補Aが「要確認（公式ヘルプに記載が見当たらないため情報担当に確認）」、候補Bが「オフラインで表示できた」。この時点で候補Aには「要確認」が残っているため、確認が済むまで決定を保留します。

### 誰と決め、どこに位置づけるか

支援ツールの選択は、担任一人の判断で完結させない方がよい場面があります。特にAACや読み書きの支援は、本人の運動機能や言語の実態に関わるため、特別支援教育コーディネーター、言語聴覚士や作業療法士などの専門職、外部の専門機関に相談できる体制があるかを先に確認しておきます。校内に相談先がない場合は、誰にどう聞くかを管理職と決めておくこと自体が準備の一つになります。

決めたことは、個別の教育支援計画や個別の指導計画のどこに位置づくのかを併せて整理します。「便利そうなので使ってみる」で始めた運用は、担当が替わったときに選んだ理由が残らず、続ける判断も見直す判断もできなくなります。支援の目標とツールの使用目的が対応していれば、引き継ぎの説明も保護者への説明も同じ言葉で行えます。

→ 計画への位置づけ方は[個別の教育支援計画・個別の指導計画の書き方](/articles/individual-education-plan-writing-guide)、合理的配慮としての整理は[特別支援教育におけるICT活用と合理的配慮](/articles/special-needs-ict-reasonable-accommodation)もご参照ください。

## まとめ

ICT支援ツールは、子どもの学びへの参加や表現の可能性を広げるために使います。「このツールを使えば解決する」という発想ではなく、「この子のこの困りごとに対して、この目的でこう使う」という具体的な場面設定が出発点です。

最初から完璧な運用を目指す必要はありません。**まずは一つの困りごとに対して、小さく試す**ことが継続のコツです。試してみて合わなければ別の方法を考え、合っていれば少しずつ場面を広げていきましょう。

ICT支援ツールの選択と活用は、子どもの実態を一番よく知っている教員と、保護者・関係機関が連携して判断するものです。特定の製品を導入することが目標ではなく、その子が「参加できている」「伝えられている」「分かっている」という状態を積み重ねることが本来のゴールです。
