## 面談1回分を、記録が閉じるところまで運ぶ

特別支援学級・通級による指導・特別支援学校、または通常の学級で支援を検討している児童生徒について、**保護者と面談・相談をする場面**を対象にします。

学期ごとの定例面談、支援の見直し、保護者からの相談申し出、いずれの場合も、教員が困りやすいのは次の点です。

- 面談の場で「その支援はできます」「それはできません」と答えてよいのか判断がつかない
- 話は聞けたが、何を記録に残せばよいのかが定まらない
- 次に誰が何をいつまでに確認するのかが曖昧なまま面談が終わる

### 面談が終わったときに手元に残るもの

1. 学校が確認できている事実と、確認できていない事項を分けた面談前のメモ
2. 本人の意向・保護者の意向・学校の説明を混ぜずに書いた面談中の記録
3. その場で答えられなかった要望を、**判断を保留したまま校内確認へつないだ**記録
4. 保留1件ごとの確認担当・確認期限・回答予定日と、回答までの経過

**この記事が引き受けない範囲。** 配慮の内容そのものの検討・申請と、実施期間・担当者・見直し時期の継続記録は[合理的配慮の記録の書き方：避けたい書き方をよい書き方へ直す書き換え表](/articles/reasonable-accommodation-school-record)へ。2つの計画の定義・違い・書き方は[個別の教育支援計画・個別の指導計画の書き方：学校現場で使える基本ガイド](/articles/individual-education-plan-writing-guide)へ。この記事が扱うのは、**面談という場の運び方と、1回分の面談記録**です。

## 面談の前日までに分けておくこと

面談前の準備は「話す内容を決めること」ではなく、**事実と未確認事項を分けておくこと**です。分けておかないと、面談中に推測で答えることになります。

### 今回の面談で決めること・決めないこと

「今回の面談で何を決めるのか／決めないのか」を先に決めます。決めない面談（情報共有だけ、相談を聞くだけ）があってよく、それを事前に共有しておくと、保護者の期待とのずれが小さくなります。

### 根拠を示せる事実だけを、事実欄に入れる

観察・記録・提出物など、**根拠を示せるもの**に限ります。

- どの場面で、どのくらいの頻度で、何が起きているか
- いつからその状態か
- 誰が確認したか（担任のみか、複数の教員か）

「落ち着きがない」のような評価語ではなく、「45分の授業のうち後半15分は離席が増える（5月・6月の記録）」のように、観察できた事実の形にします（この例は架空のものです）。

### いま行っている支援と、始めた理由

- 何を、いつから、どの場面で行っているか
- その支援を始めた理由
- 現時点で分かっている変化（変化がない場合は「変化が確認できていない」と書く）

### 本人の意思は、未確認なら「未確認」と書く

発達段階に応じて、本人が学校生活について何を望んでいるかを、可能な範囲で事前に確認しておきます。本人に確認できていない場合は、**「未確認」と明記**します。保護者の意向を本人の意思として扱わないためです。

### 保護者に確認したいことを絞る

学校側から質問したい事項を事前に絞ります。家庭生活の詳細を広く聞き取ることが目的ではなく、**学校での支援を調整するために必要な範囲**に限ります。

### その場では答えない、と面談前に決めておく事項

次に当てはまるものは、**面談前の時点で「その場では答えない」と決めておきます**。

- 人的配置・時間割・教室環境の変更を伴うもの
- 費用が発生するもの
- 他の児童生徒の学習環境に影響するもの
- 評価・成績の取扱いに関わるもの
- 進学・就学先の決定に関わるもの
- 前例がなく、校内で判断した記録がないもの

### 担任の裁量で動かせるのは、3条件をすべて満たすものだけ

上の除外リストに当たらないから裁量、という消去法では判断できません。本サイトの整理では、**担任の判断で動かせる**のは、次の3条件を**すべて**満たすものに限ります。

1. すでに行っている指導の枠組みの中で調整できる（新たな人員・時間・予算を必要としない）
2. 他の児童生徒・時間割・予算・**評価の取扱い**に波及しない
3. うまくいかなければ元に戻せる

3つのうち1つでも欠けるものは、次の判断手順で保留に回します。

## 面談中の記録は、出所ごとに分ける

面談中の記録は、**出所ごとに分けて**書きます。後から「誰がそう言ったのか」が分からなくなることを防ぐためです。

| 区分 | 書く内容 | 混ぜないための目安 |
|---|---|---|
| 確認できた事実 | 学校・家庭で実際に観察された出来事 | 「〜と思われる」は事実欄に書かない |
| 本人の意向 | 本人が述べたこと。未確認なら「未確認」 | 保護者の発言を本人の意向欄に書かない |
| 保護者の意向 | 保護者が述べた希望・心配 | 学校側の解釈を加えずに書く |
| 学校から説明したこと | 現在の支援、その理由、制約 | 約束していないことを書かない |
| 検討可能な支援 | その場で「検討する」と伝えたもの | 「実施する」と書かない |
| 校内確認へ持ち帰る事項 | 判断を保留した要望 | 誰に確認するかまで書く |

## その場で「できます／できません」と即答しないための判断手順

即答を避けるのは、対応を渋るためではなく、**担任個人では判断材料が揃わない事項があるため**です。

### なぜ即答を避けるのか

障害者差別解消法は、合理的配慮について次のように定めています。

> 〔行政機関等は、その事務又は事業を行うに当たり、〕障害者から現に社会的障壁の除去を必要としている旨の**意思の表明があった場合**において、その実施に伴う**負担が過重でないとき**は、障害者の権利利益を侵害することとならないよう、当該障害者の性別、年齢及び障害の状態に応じて、社会的障壁の除去の実施について必要かつ合理的な配慮を**しなければならない**
> — 障害者差別解消法 第7条第2項。事業者（私立学校等）については第8条第2項が同旨を定めています（2024年4月1日施行の改正により、努力義務から義務になりました）。

ここから、面談の場での実務上の含意が2つ出てきます。

1. **保護者・本人からの申し出は、それ自体が起点として扱われる。** 「様子を見ましょう」で終わらせず、受け止めた記録を残す必要があります。なお条文の主語は「障害者から」ですが、意思の表明が困難な場合に家族・支援者等が本人を補佐して行う表明を含むこと、および表明がない場合にも建設的対話を働きかけることが望ましいとされる点は、文部科学省の対応指針に示されています。
2. **「負担が過重かどうか」は、担任個人が単独で判定できる事項ではありません。** 人的配置・予算・他の児童生徒への影響を含む判断だからです。したがって、その場で「できません」と答えることは、判断材料を持たないまま結論を出すことになります。

同じ理由で、その場で「できます」と答えることにも同じリスクがあります。実施できなかったときに、学校への信頼が損なわれます。

### 聞く → 保留 → 校内確認 → 回答までの並び

```
① 要望を聞く（遮らずに最後まで）
      ↓
② 本人の教育的ニーズを確認する
   「どの場面で、何に困っているか」へ言い換えて確認する
      ↓
③ 現在の支援・環境を確認する
   すでに行っていることを共有する（重複要望なら、その場で整理できる）
      ↓
④ その場で判断可能か
   ├─ 可能（担任の裁量の範囲・すでに校内で判断済み）
   │      ↓
   │   ⑥へ
   └─ 不可（人的配置・費用・評価・他児童への影響・前例なし）
          ↓
⑤ 誰に確認するかを、その場で保護者に伝える
   「いつまでに」「誰から」回答するかを伝える
          ↓
⑤' 校内で検討する
   誰に・どの会議で・何を材料に検討するかを決めて動かす
   （校内委員会の開催周期や管理職の不在で止まりやすい工程）
          ↓
⑥ 回答する（保留した場合は期限内に）
   実施できない場合は、①判断の理由 ②代替案 ③再検討の条件 を必ずセットで伝える
      ↓
⑦ 面談の最後に読み合わせる
   合意事項・保留事項・回答予定日を口頭で確認し、認識のずれをその場で潰す
      ↓
⑧ 記録する（合意・保留を区別して）
      ↓
⑨ 見直しの時期を、保護者と一緒に決める
```

⑤で校内の誰に・どの順で相談するかは、[特別支援教育における行動記録の取り方：支援に生かす観察と記録の基本](/articles/special-needs-behavior-record-guide)の「共有・相談の順番」にあります。この記事が引き受けるのは、その相談先を**保護者にどう伝えるか**です。

### ⑤' を飛ばして⑥へは進めない

⑤' を飛ばして⑥へ進むことはできません。**「誰に聞くか」を伝えただけでは検討は始まりません。** 誰が・どの会議に・何を材料に持ち込むかまで決めて、はじめて期限を守れる形になります。

### ⑤で保護者に伝える言い方の例

即答を避けることと、要望を退けることは違います。その違いが伝わる言い方にします。

| 場面 | 避けたい言い方 | 言い換えの例 |
|---|---|---|
| 判断を保留する | 「難しいと思います」 | 「その場でお答えできる範囲を超えるので、◯◯に確認して△日までにご連絡します」 |
| 回答に時間がかかりそう | 期限だけ確約する | 「△日までに、**いったん検討の経過を**ご連絡します」（結論を約束できないときは中間報告の期日を約束する） |
| 確認先を伝える | 「上に聞いてみます」 | 「校内の担当（特別支援教育コーディネーター）に確認し、必要に応じて管理職にも相談します」 |
| 一部だけ対応できる | 「全部は無理です」 | 「◯◯は今週から始められます。△△は確認が必要です」 |
| 前例がない | 「前例がないので」 | 「学校としてこれまで検討したことのないご相談ですので、どう検討するかを含めて確認し、△日までに経過をご連絡します」 |

## 面談1回分の記録シート（本サイト作成の参考様式）

> **本サイト作成の参考様式です。** 文部科学省・教育委員会等が定める公式様式ではありません。所属校・設置者に定められた様式がある場合は、そちらを使用してください。

記録の目的は、監視や責任回避ではなく、**次の担当者が同じ説明を保護者に求めなくて済むようにすること**です。

このシートが持つのは**面談1回分**だけです。配慮の内容・実施期間・担当者・見直し時期は、[合理的配慮の記録の書き方：避けたい書き方をよい書き方へ直す書き換え表](/articles/reasonable-accommodation-school-record)の記録項目へ転記して継続管理します。

### 空欄様式

| 項目 | 記入欄 |
|---|---|
| 面談日・場所・参加者 |  |
| 面談の目的（決めること／決めないこと） |  |
| 学校で確認した事実 |  |
| 現在行っている支援 |  |
| 本人の意向（未確認の場合は「未確認」） |  |
| 保護者の意向・要望 |  |
| 学校から説明したこと |  |
| 合意事項（この面談の場で合意した内容） |  |

| 保護者への控えの取扱い |  |

埋められない欄は空欄のままにし、推測で埋めません。「未確認」「保護者からの申し出なし」など、状態が分かる書き方にします。

### 保留事項は1件1行で、確認期限と回答予定日を別の日に置く

校内確認が必要なものを**1件1行**で並べます。**確認期限**は校内で判断を出す締切、**回答予定日**は保護者へ伝える日です。同じ日にすると、校内の判断が遅れた分がそのまま保護者への遅れになるため、別の日に置きます。右側3列は**確認後に追記**し、ここまで埋まってはじめてその1件が閉じます。

| # | 保留事項 | 確認担当 | 確認期限 | 回答予定日 | 確認結果（いつ・誰が・何を判断したか） | 回答した日・方法・内容 | 保護者の応答 |
|---|---|---|---|---|---|---|---|
| 1 |  |  |  |  |  |  |  |
| 2 |  |  |  |  |  |  |  |

> **保護者が読む可能性がある前提で書きます。** 公立学校の面談記録は保有個人情報として、本人・保護者から開示を求められることがあります。評価的な表現ではなく、観察した事実と、学校が説明した内容を書きます。

## 面談の場で誤って説明しやすい、計画の根拠規定

個別の教育支援計画と個別の指導計画の定義、2つの計画の違い、書き方・様式は[個別の教育支援計画・個別の指導計画の書き方：学校現場で使える基本ガイド](/articles/individual-education-plan-writing-guide)にあります。ここで扱うのは、**面談の場で口頭の説明がずれやすい2点**だけです。いずれも根拠は**個別の教育支援計画**の規定です。

### 「同意をいただいたので共有します」と言い換えない

> 校長は、特別支援学校に在学する児童等について個別の教育支援計画…を作成しなければならない。
> ２ 校長は、前項の規定により個別の教育支援計画を作成するに当たつては、当該児童等**又はその保護者の意向を踏まえつつ**、あらかじめ、関係機関等と当該児童等の支援に関する必要な情報の共有を図らなければならない。
> — 学校教育法施行規則 第134条の2

条文は「**意向を踏まえつつ**」であり、「同意を得て」とは書かれていません。個人情報の取扱いは次章のとおり別の法令で規律されるため、**面談の場で「同意をいただいたので共有します」と単純化して説明しない**ほうが安全です。あわせて、情報共有は「**あらかじめ**」とされており、計画作成後の事後共有を前提にしない趣旨で読めます。

### 「特別支援学級・通級には作成義務がない」と説明しない

第134条の2は特別支援学校を直接の対象とする規定ですが、**施行規則は同条を準用しています**。

> 第百三十九条の二　第百三十四条の二の規定は、小学校、中学校若しくは義務教育学校又は中等教育学校の前期課程における**特別支援学級**の児童又は生徒について準用する。

> 第百四十一条の二　第百三十四条の二の規定は、第百四十条の規定により特別の指導が行われている児童又は生徒について準用する。

第140条は通級による指導を定める規定（小学校・中学校・義務教育学校・**高等学校**・中等教育学校）なので、第141条の2は高等学校の通級にも及びます。したがって、**特別支援学級・通級による指導についても、校長による作成義務と「意向を踏まえつつ、あらかじめ関係機関等と情報共有」の規定は同様に及びます**。設置者の裁量で作成の要否を決める、という性質のものではありません。

一方、**通常の学級に在籍し、通級による指導を受けていない**児童生徒については、施行規則上のこの作成義務の規定はなく、学習指導要領および設置者の定めによります。いずれの場合も、**様式・記載事項・保管・引継ぎの手順は所属校・設置者の定めを確認してください。**

なお、面談記録は計画そのものではありません。記録は「その日に何を確認し、何を保留したか」を残すもの、計画は「長期的な支援の方向性」を示すものです。1つの文書で兼ねると、記録としても計画としても参照しにくくなるため、分けて扱います。

## 面談で聞いた情報を校外へ出すときの区分

面談の場で「同意をいただければ外部機関に共有できます」と説明してよいかは、学校の区分によって変わります。**設置者の区分によって適用される条文が異なります**。

| 学校の区分 | 適用される規定 | 条文の要点 |
|---|---|---|
| 公立学校（大学を除く。行政機関等） | 個人情報保護法 第69条 | 「行政機関の長等は、**法令に基づく場合を除き、利用目的以外の目的のために**保有個人情報を自ら利用し、又は提供してはならない」 |
| 私立学校（学校法人。個人情報取扱事業者） | 個人情報保護法 第27条 | 「個人情報取扱事業者は、次に掲げる場合を除くほか、**あらかじめ本人の同意を得ないで**、個人データを第三者に提供してはならない」 |
| **国立大学法人立・公立大学法人立の学校**（附属特別支援学校・附属小中学校等） | 個人情報保護法 **第27条** | 国立大学法人・大学共同利用機関法人は別表第二の法人として、公立大学法人は地方独立行政法人法**第21条第2号**（大学等の設置及び管理）の業務を目的とする法人として、**いずれも第2条第11項により「行政機関等」から除かれます**（＝個人情報取扱事業者の側）。なお同法第68条は「一般地方独立行政法人で第二十一条第二号に掲げる業務を行うもの」を公立大学法人と定義しています |

公立学校では、まず**利用目的の範囲内か**が問われます。目的外の利用・提供は原則禁止ですが、第69条第2項第1号は「本人の同意があるとき、又は本人に提供するとき」を例外に挙げており、同意が無意味になるわけではありません。「**目的内か → 目的外なら第69条第2項のどの号に当たるか**」という順序で検討します。私立学校等では、第27条により本人（保護者）の同意が原則の要件になります。

**面談の場でどの説明をするかは、所属校の規程を確認してから決めてください。** 面談中に規程を確認できないときは、共有の可否そのものを保留事項に立て、確認担当と確認期限を書きます。

> **区分が法律によって逆転する点に注意してください。** 国立大学法人立・公立大学法人立の学校は、**障害者差別解消法では第7条第2項（行政機関等）**、**個人情報保護法では第27条**（個人情報取扱事業者の側）という組合せになります。

### 保護者の同意を前提としない場合がある

上記2条にはいずれも「**法令に基づく場合**」の例外があります。面談では、児童虐待の疑いなど、**保護者の同意を前提とせずに通告する必要が生じる情報**が出ることがあります。

> 第六条　児童虐待を受けたと思われる児童を発見した者は、速やかに、これを市町村、都道府県の設置する福祉事務所若しくは児童相談所…に通告しなければならない。
> ３　刑法…の秘密漏示罪の規定その他の**守秘義務に関する法律の規定は、第一項の規定による通告をする義務の遵守を妨げるものと解釈してはならない**。
> — 児童虐待の防止等に関する法律 第6条

通告義務は「児童虐待を受けたと**思われる**」段階で発生し、**保護者の同意を要件としていません**。第3項は、守秘義務がこの義務の妨げにならないことを明示しています。

なお、自傷や希死念慮など生命・身体に関わる情報の共有は、この第6条の通告義務とは根拠が異なります（個人情報保護法 第27条第1項第2号「人の生命、身体又は財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき」、公立学校では第69条第2項の該当号）。

**この判断は担任個人で抱えず、直ちに管理職に報告してください。** 「保護者の同意が得られないから外部に出せない」という整理は、この場面には当てはまりません。

校内での共有範囲・保管場所・廃棄の決め方は[個別の教育支援計画・個別の指導計画の書き方：学校現場で使える基本ガイド](/articles/individual-education-plan-writing-guide)の「共有範囲・保管・廃棄をどう決めるか」に、生成AIに児童生徒・保護者の情報を入力しない判断は[学校の校務で生成AIを使う前の判断ガイド](/articles/ai-koomu-kaizen-nyumon)の校務ゲート2にまとめています。

## この記事の適用限界

- **学校・設置者ごとに手順が異なります。** 面談の様式、記録の保管、外部機関との連携手続きは所属校の定めが優先します。
- **法的判断の代替ではありません。** 個別の事案が合理的配慮の提供義務に当たるか、過重な負担に当たるかは、本記事では判断できません。
- **医療的判断の代替ではありません。** 学校は診断を行う場ではありません。診断の有無や障害名について、学校から保護者に判断を求めることはしません。
- **就学・進路の手続きは自治体によって異なります。** 就学相談の窓口・時期・手続きは、教育委員会に確認してください。
- 個別の案件では、特別支援教育コーディネーター・管理職に相談してください。
