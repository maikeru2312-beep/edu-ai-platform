## 総括

再構成後の15本は、**教員が一人で決めてよい範囲と、渡すべき範囲の線引き**という点で、この種のサイトとしてはかなり精度が高い状態にあります。特に評価できるのは3点です。

第一に、停止条件が「注意しましょう」ではなく判定語として実装されていること。free-ict の USE/HOLD/DO NOT USE は「まだ分からないは DO NOT USE ではなく HOLD」（L99）まで定義し、HOLD には期限と代替手段の欄（L334-335）を強制しています。ai-koomu の判断シートは「止まったゲートと、その理由」を主目的の欄として置き（L177-181）、「全部を『利用する』に持っていく必要はありません」（L165）と明言します。止まった記録が残る設計は、次年度の担任の作業を実際に減らします。

第二に、「担任の裁量」を消去法で定義していないこと。parent-collaboration L74-82 の3条件（新たな人員・時間・予算を要しない／他児童・時間割・予算・**評価の取扱い**に波及しない／元に戻せる）と、記入例で同一要望を提示のしかた（裁量）と分量（保留）に割った実演は、面談の場でそのまま使えます。

第三に、架空例の扱いと効果を主張しない姿勢が徹底していること。「この記事は効果を測っていません」が複数記事に置かれ、newsletter は架空例の曜日についてまで注意を書いています。

一方で、指摘した13件には**共通の型**があります。**「始める側は厳密、続ける・終わる・失敗する側が薄い」**という偏りです。F-03（フォームで情報が出たあと）、F-02（いつまで保管するか＝終わりの期限）、F-12（支援を薄くする・やめる）は、いずれも「始めてよいか」の判断が終わったあとの領域で、ここだけ他と同じ密度で書かれていません。F-01 も同型で、「記録を始めるときの様式」は用意されているのに、その様式が「うまくいっている条件を残す」という継続側の目的を実装していません。

**BLOCK にしなかった理由**は、これらがいずれも欠落であって誤りではなく、既存の枠組み（ai-koomu の事故時4手順、reasonable-accommodation の終了時の合意確認、free-ict の HOLD と期限）を該当記事へ展開すれば埋まるためです。児童生徒に不利益を与える手順や、教員に危険な操作をさせる記述は見つかりませんでした。

**優先順位をつけるなら、F-01 → F-02 → F-03 の順です。** F-01 は、記事が自分の様式について事実と異なる説明をしている点で読者が誤りに気づけず、かつ特別支援教育の記録で最も起きやすい偏り（困難だけを集める）をサイト側の様式が再生産します。F-02 は、書けと要求されている欄の答えがサイト内に存在しないという、最も明確な行き止まりです。F-03 は、発生確率は低いものの、起きたときの影響がフォームの配布規模に比例します。F-04（印刷不能）は影響範囲が広い一方、印刷用CSSの追加という単一の技術的対応で10件すべてが解消するため、実装コストあたりの効果は最も高くなります。
