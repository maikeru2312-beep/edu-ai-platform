## 回答方法

各記事について、次の形式で回答してください。

- 経験: `A 実際に担当した` / `B 見聞・支援した` / `C 資料でのみ確認` / `D 未経験` / `E 回答しない`
- 手順: `A 整合する` / `B 一部修正が必要` / `C 判断できない`
- 成果物: `A そのまま使える` / `B 修正すれば使える` / `C 公開しない方がよい`
- 公開可否: `A 匿名で一般化して公開可` / `B 個別確認後なら可` / `C 経験としては公開不可`
- 短文: 個人情報を含めず、直すべき点を1〜3文
