## 18. Human review 対応（2026-09-10、READY_AFTER_TARGETED_FIXES への修正）

1. 公立学校と「地方公共団体の機関」（P0）: 「公立学校は行政機関等に当たる」を、個人情報保護委員会 Q&A（行政機関等編）Q2-1-2 に合わせて「教育委員会が所管する公立学校では、学校自体ではなく所管する教育委員会が地方公共団体の機関に該当する」に修正（校務AIハブ2か所。同じ言い回しを持つ外部ICT記事・面談記事の各1か所と、参考資料の supports 2件も揃えた）。Q&A を参考資料に登録。国立・私立学校へは広げていない。
2. Googleフォームのオーナー移管: 「本人は転出後に移せなくなります」を、Google ドライブ ヘルプ（職場・学校アカウントでは組織内にのみ譲渡でき、役割変更・離職時は Google Workspace 管理者が一括譲渡できる）に合わせ、本人による移管ができなくなる可能性と管理者による移管の余地を併記した運用文に修正（本文と記入例の2か所）。ヘルプを参考資料に登録。
3. AAC: 研究知見の一般化（根拠の有無）を削り、本人のコミュニケーション上のニーズを基に検討し、必要に応じて専門職と相談する運用文に修正。
4. AIサービス記事: 「確認の責任は学校側に残る」を、利用前に内容を確認するという運用要件に修正（責任の帰属は述べない）。
5. 内部リンク: レビューパケット上で内部リンクが外部ドメイン付きで表示されたのは表示側の加工であり、リポジトリ内の記事・ページ・部品に当該ドメインへのリンクは0件（`/articles/...` 等のサイト内パスのみ）。
6. AdSense の実態と開示: production の記事ページには AdSense スクリプトが設置され（client 有効、記事ページのみ）、広告枠は無く広告は表示されないが、Google の広告配信サーバーとの通信と Cookie（googleads.g.doubleclick.net の test_cookie）が Lighthouse 計測で観測された。Privacy と About を「コードは設置済み・広告は未表示・表示されなくても通信と Cookie が生じうる」に改めた。読み込み方法は変更していない。
7. LCP の因果の書き方を「主要因である可能性が高いが、production と local の比較だけでは因果分離にならない。次フェーズで production 相当環境の A/B 計測」に改めた（§8・§12・§16）。
